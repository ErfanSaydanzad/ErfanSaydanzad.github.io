9.1Ordinary, Regular Singular, and Irregular Points

Consider the second–order linear differential equation

y ″ + P ( x ) y ′ + Q ( x ) y = 0 , (9.1)

where P ( x ) and Q ( x ) are known functions.

DefinitionAnalytic function

A function f ( x ) is called analytic at x = x 0 if it can be written as a convergent power series in a neighborhood of x 0 :

f ( x ) = ∑ n = 0 ∞ c n ( x − x 0 ) n . (9.2)

Analytic functions are finite, smooth, and well behaved near x 0 .

Definition

A point x = x 0 of the differential equation is classified as follows:

  • Ordinary point: x 0 is an ordinary point if both P ( x ) and Q ( x ) are analytic at x 0 . All coefficients are finite and smooth, so we may solve the equation using a standard power–series (Taylor) expansion

    y ( x ) = ∑ n = 0 ∞ A n ( x − x 0 ) n . (9.3)

  • Regular singular point: x 0 is a regular singular point if P ( x ) or Q ( x ) diverge at x 0 , but the combinations

    ( x − x 0 ) P ( x ) , ( x − x 0 ) 2 Q ( x ) (9.4)

    are analytic at x 0 . The singularity is “mild’’ and the correct solution method is the Frobenius method, which assumes

    y ( x ) = ∑ n = 0 ∞ a n ( x − x 0 ) n + r , a 0 ≠ 0. (9.5)

    This produces an indicial equation for r and a recurrence for a n .

  • Irregular singular point: If even ( x − x 0 ) P ( x ) or ( x − x 0 ) 2 Q ( x ) fail to be analytic, then the point is an irregular singular point. The singularity is “too strong’’ and ordinary series or Frobenius methods typically fail.

Remark

  • At an ordinary point, use a Taylor series.

  • At a regular singular point, use the Frobenius series.

  • Many special functions in physics—Legendre, Bessel, Hermite, Laguerre—originate from equations with regular singular points, where Frobenius expansions naturally apply.

Example(ordinary point): Solve y ′ = 2 x y by two methods

We solve

y ′ = 2 x y (9.6)

by (1) the standard separable method and (2) a power–series method about x 0 = 0 .

Method 1: Standard (separable) solution.

For y ≠ 0 ,

d y d x = 2 x y ⟹ 1 y d y = 2 x d x . (9.7)

Integrate both sides:

∫ 1 y d y = ∫ 2 x d x ⟹ ln ⁡ | y | = x 2 + C . (9.8)

Exponentiate:

| y | = e x 2 + C = e C e x 2 . (9.9)

Let C 1 = ± e C (an arbitrary constant), then

y ( x ) = C 1 e x 2 . (9.10)

Allowing C 1 = 0 also includes the trivial solution y ≡ 0 :

y ( x ) = C 1 e x 2 , C 1 ∈ R . (9.11)

Method 2: Power–series solution about x 0 = 0 .

Assume a power series

y ( x ) = ∑ n = 0 ∞ a n x n , (9.12)

so

y ′ ( x ) = ∑ n = 1 ∞ n a n x n − 1 . (9.13)

Substitute into y ′ = 2 x y :

∑ n = 1 ∞ n a n x n − 1 = 2 x ∑ n = 0 ∞ a n x n = 2 ∑ n = 0 ∞ a n x n + 1 . (9.14)

Align the powers of x .

On the left, set m = n − 1 :

∑ m = 0 ∞ ( m + 1 ) a m + 1 x m . (9.15)

On the right, write the sum with index m :

2 ∑ m = 1 ∞ a m − 1 x m . (9.16)

Thus

∑ m = 0 ∞ ( m + 1 ) a m + 1 x m = 2 ∑ m = 1 ∞ a m − 1 x m . (9.17)

For m = 0 , only the left sum contributes:

( 0 + 1 ) a 1 = 0 ⟹ a 1 = 0. (9.18)

For m ≥ 1 , equate coefficients of x m :

( m + 1 ) a m + 1 = 2 a m − 1 , m ≥ 1. (9.19)

So the recurrence is

a m + 1 = 2 m + 1 a m − 1 , m ≥ 1. (9.20)

Compute the coefficients.

m = 1 : 2 a 2 = 2 a 0 ⇒ a 2 = a 0 , m = 2 : 3 a 3 = 2 a 1 = 0 ⇒ a 3 = 0 , m = 3 : 4 a 4 = 2 a 2 = 2 a 0 ⇒ a 4 = a 0 2 ! , m = 5 : 6 a 6 = 2 a 4 = a 0 ⇒ a 6 = a 0 3 ! ,   … (9.21)

We see

a 2 k = a 0 k ! , a 2 k + 1 = 0 , k = 0 , 1 , 2 , … (9.22)

Therefore

y ( x ) = a 0 ( 1 + x 2 + x 4 2 ! + x 6 3 ! + ⋯ ) = a 0 ∑ k = 0 ∞ x 2 k k ! = a 0 e x 2 . (9.23)

Renaming a 0 as C 1 , we obtain the same family of solutions:

y ( x ) = C 1 e x 2 , C 1 ∈ R . (9.24)

9.2Legendre’s Differential Equation

Many physical systems with spherical symmetry—electrostatics, gravitational potentials, quantum mechanics, and classical wave equations—lead to the Legendre differential equation:

( 1 − x 2 ) y ″ − 2 x y ′ + ℓ ( ℓ + 1 ) y = 0 , ℓ = 0 , 1 , 2 , … (9.25)
Remark

The points x = ± 1 are regular singular points, while x = 0 is an ordinary point. Therefore ordinary power series work at the center, and Frobenius-type behavior appears at the endpoints.

9.2.1Power–Series Solution About x = 0 (Ordinary Point)

We now derive the recurrence relation for the coefficients a n .

Assume a power–series solution about the ordinary point x = 0 :

y ( x ) = ∑ n = 0 ∞ a n x n . (9.26)

Then

y ′ ( x ) = ∑ n = 1 ∞ n a n x n − 1 , y ″ ( x ) = ∑ n = 2 ∞ n ( n − 1 ) a n x n − 2 . (9.27)

Substitute these into Legendre’s equation

( 1 − x 2 ) y ″ − 2 x y ′ + ℓ ( ℓ + 1 ) y = 0 : (9.28)
( 1 − x 2 ) ∑ n = 2 ∞ n ( n − 1 ) a n x n − 2 − 2 x ∑ n = 1 ∞ n a n x n − 1 + ℓ ( ℓ + 1 ) ∑ n = 0 ∞ a n x n = 0. (9.29)

First expand the product ( 1 − x 2 ) y ″ :

( 1 − x 2 ) y ″ = ∑ n = 2 ∞ n ( n − 1 ) a n x n − 2 − ∑ n = 2 ∞ n ( n − 1 ) a n x n . (9.30)

Now shift indices so that every sum is in powers of x n .

For the first sum, let k = n − 2 (equivalently n = k + 2 ):

∑ n = 2 ∞ n ( n − 1 ) a n x n − 2 = ∑ k = 0 ∞ ( k + 2 ) ( k + 1 ) a k + 2 x k . (9.31)

Renaming k back to n ,

∑ n = 0 ∞ ( n + 2 ) ( n + 1 ) a n + 2 x n . (9.32)

The other sums already have powers x n (we can extend the lower limit to 0 , since the missing terms are zero):

− ∑ n = 2 ∞ n ( n − 1 ) a n x n = − ∑ n = 0 ∞ n ( n − 1 ) a n x n , (9.33)
− 2 x ∑ n = 1 ∞ n a n x n − 1 = − 2 ∑ n = 1 ∞ n a n x n = − 2 ∑ n = 0 ∞ n a n x n , (9.34)
ℓ ( ℓ + 1 ) ∑ n = 0 ∞ a n x n = ∑ n = 0 ∞ ℓ ( ℓ + 1 ) a n x n . (9.35)

Putting all pieces together:

∑ n = 0 ∞ ( n + 2 ) ( n + 1 ) a n + 2 x n − ∑ n = 0 ∞ n ( n − 1 ) a n x n − 2 ∑ n = 0 ∞ n a n x n + ∑ n = 0 ∞ ℓ ( ℓ + 1 ) a n x n = 0. (9.36)

Combine the last three sums:

∑ n = 0 ∞ [ ( n + 2 ) ( n + 1 ) a n + 2 + ( ℓ ( ℓ + 1 ) − n ( n − 1 ) − 2 n ) a n ] x n = 0. (9.37)

Note that

n ( n − 1 ) + 2 n = n 2 − n + 2 n = n 2 + n = n ( n + 1 ) , (9.38)

so

ℓ ( ℓ + 1 ) − n ( n − 1 ) − 2 n = ℓ ( ℓ + 1 ) − n ( n + 1 ) . (9.39)

Thus

∑ n = 0 ∞ [ ( n + 2 ) ( n + 1 ) a n + 2 + ( ℓ ( ℓ + 1 ) − n ( n + 1 ) ) a n ] x n = 0. (9.40)

For this identity to hold for all x , each coefficient of x n must vanish:

( n + 2 ) ( n + 1 ) a n + 2 + ( ℓ ( ℓ + 1 ) − n ( n + 1 ) ) a n = 0. (9.41)

Solving for a n + 2 gives the recurrence

a n + 2 = n ( n + 1 ) − ℓ ( ℓ + 1 ) ( n + 1 ) ( n + 2 ) a n , n = 0 , 1 , 2 , … (9.42)

which determines all higher coefficients from a 0 and a 1 . Starting from the recurrence relation

a n + 2 = n ( n + 1 ) − ℓ ( ℓ + 1 ) ( n + 1 ) ( n + 2 ) a n , n = 0 , 1 , 2 , … , (9.43)

we compute the first few coefficients.

Coefficient a 2 .

Set n = 0 :

a 2 = 0 ⋅ 1 − ℓ ( ℓ + 1 ) 1 ⋅ 2 a 0 = − ℓ ( ℓ + 1 ) 2 a 0 . (9.44)

Coefficient a 3 .

Set n = 1 :

a 3 = 1 ⋅ 2 − ℓ ( ℓ + 1 ) 2 ⋅ 3 a 1 = 2 − ℓ ( ℓ + 1 ) 6 a 1 = − ℓ ( ℓ + 1 ) − 2 3 ! a 1 = − ( ℓ − 1 ) ( ℓ + 2 ) 3 ! a 1 . (9.45)

Coefficient a 4 .

Set n = 2 :

a 4 = 2 ⋅ 3 − ℓ ( ℓ + 1 ) 3 ⋅ 4 a 2 = 6 − ℓ ( ℓ + 1 ) 12 a 2 . (9.46)

Using a 2 = − ℓ ( ℓ + 1 ) 2 a 0 :

a 4 = 6 − ℓ ( ℓ + 1 ) 12 ( − ℓ ( ℓ + 1 ) 2 a 0 ) = − ℓ ( ℓ + 1 ) ( 6 − ℓ ( ℓ + 1 ) ) 24 a 0 . (9.47)

Since 6 − ℓ ( ℓ + 1 ) = − ( ℓ − 2 ) ( ℓ + 3 ) , this becomes

a 4 = ℓ ( ℓ + 1 ) ( ℓ − 2 ) ( ℓ + 3 ) 4 ! a 0 . (9.48)

Coefficient a 5 .

Set n = 3 :

a 5 = 3 ⋅ 4 − ℓ ( ℓ + 1 ) 4 ⋅ 5 a 3 = 12 − ℓ ( ℓ + 1 ) 20 a 3 . (9.49)

Using a 3 = 2 − ℓ ( ℓ + 1 ) 6 a 1 :

a 5 = 12 − ℓ ( ℓ + 1 ) 20 ⋅ 2 − ℓ ( ℓ + 1 ) 6 a 1 = ( 12 − ℓ ( ℓ + 1 ) ) ( 2 − ℓ ( ℓ + 1 ) ) 120 a 1 . (9.50)

Factoring,

( 12 − ℓ ( ℓ + 1 ) ) ( 2 − ℓ ( ℓ + 1 ) ) = ( ℓ − 1 ) ( ℓ + 2 ) ( ℓ − 3 ) ( ℓ + 4 ) , (9.51)

so

a 5 = ( ℓ − 1 ) ( ℓ + 2 ) ( ℓ − 3 ) ( ℓ + 4 ) 5 ! a 1 . (9.52)

Therefore

a 2 = − ℓ ( ℓ + 1 ) 2 a 0 , a 3 = − ( ℓ − 1 ) ( ℓ + 2 ) 3 ! a 1 , a 4 = ℓ ( ℓ + 1 ) ( ℓ − 2 ) ( ℓ + 3 ) 4 ! a 0 , a 5 = ( ℓ − 1 ) ( ℓ + 2 ) ( ℓ − 3 ) ( ℓ + 4 ) 5 ! a 1 . (9.53)
Remark

Even coefficients depend only on a 0 ; odd coefficients depend only on a 1 . Thus the general solution splits into two independent series: one even in x , built from a 0 , and one odd in x , built from a 1 .

y ( x ) = ∑ n = 0 ∞ a n x n = a 0 [ 1 − ℓ ( ℓ + 1 ) 2 ! x 2 + ℓ ( ℓ + 1 ) ( ℓ − 2 ) ( ℓ + 3 ) 4 ! x 4 − ⋯ ] + a 1 [ x − ( ℓ − 1 ) ( ℓ + 2 ) 3 ! x 3 + ( ℓ − 1 ) ( ℓ + 2 ) ( ℓ − 3 ) ( ℓ + 4 ) 5 ! x 5 − ⋯ ] . (9.54)

9.2.2Polynomial Solutions: the Legendre Polynomials

Now restrict to the physically important case where ℓ is a non-negative integer. The recurrence factor

n ( n + 1 ) − ℓ ( ℓ + 1 ) (9.55)

vanishes when n = ℓ . Since even coefficients use n = 0 , 2 , 4 , … and odd coefficients use n = 1 , 3 , 5 , … , the vanishing occurs either in the even or odd subsequence:

  • If ℓ is even, then n = ℓ appears in the even subsequence. The even series terminates at x ℓ ; set a 1 = 0 , a 0 ≠ 0 .

  • If ℓ is odd, then n = ℓ appears in the odd subsequence. The odd series terminates at x ℓ ; set a 0 = 0 , a 1 ≠ 0 .

Thus for each integer ℓ , exactly one of the two series becomes a finite polynomial of degree ℓ . This terminating series, normalized by P ℓ ( 1 ) = 1 , is the Legendre polynomial P ℓ ( x ) .

  • Even ℓ : P ℓ ( x ) comes from the even series (an even function of x ).

  • Odd ℓ : P ℓ ( x ) comes from the odd series (an odd function of x ).

We now illustrate this for ℓ = 0 , 1 , 2 , 3 , 4 , always normalizing with P ℓ ( 1 ) = 1 .

Case ℓ = 0

Here ℓ ( ℓ + 1 ) = 0 . The even series gives

a 0 [ 1 − 0 ⋅ x 2 + 0 ⋅ x 4 − ⋯ ] = a 0 . (9.56)

The odd series does not terminate. To obtain the polynomial solution, choose a 0 ≠ 0 and set a 1 = 0 . Normalization P 0 ( 1 ) = 1 gives a 0 = 1 , hence

P 0 ( x ) = 1. (9.57)

Case ℓ = 1

Here ℓ ( ℓ + 1 ) = 2 . The odd series is

a 1 [ x − 2 − 2 3 ! x 3 + ⋯ ] = a 1 x , (9.58)

since the coefficient of x 3 vanishes. The even series does not terminate. To get the polynomial, choose a 1 ≠ 0 , a 0 = 0 . With P 1 ( 1 ) = 1 , we take a 1 = 1 and obtain

P 1 ( x ) = x . (9.59)

Case ℓ = 2

Here ℓ ( ℓ + 1 ) = 6 . The even series begins

a 0 [ 1 − 6 2 ! x 2 + ⋯ ] = a 0 [ 1 − 3 x 2 + ⋯ ] . (9.60)

At n = 2 , the factor n ( n + 1 ) − ℓ ( ℓ + 1 ) = 6 − 6 = 0 , so a 4 and all higher even coefficients vanish and the even series terminates at x 2 :

a 0 ( 1 − 3 x 2 ) . (9.61)

The odd series does not terminate. Choose a 0 ≠ 0 , a 1 = 0 and normalize with P 2 ( 1 ) = 1 . Since the polynomial at x = 1 is a 0 ( 1 − 3 ) = − 2 a 0 ,

− 2 a 0 = 1 ⇒ a 0 = − 1 2 , (9.62)

so

P 2 ( x ) = − 1 2 ( 1 − 3 x 2 ) = 1 2 ( 3 x 2 − 1 ) . (9.63)

Case ℓ = 3

Here ℓ ( ℓ + 1 ) = 12 . The odd series is

a 1 [ x − 12 − 2 3 ! x 3 + ⋯ ] = a 1 [ x − 10 6 x 3 + ⋯ ] = a 1 [ x − 5 3 x 3 + ⋯ ] . (9.64)

At n = 3 , the factor n ( n + 1 ) − ℓ ( ℓ + 1 ) = 12 − 12 = 0 , so higher odd coefficients vanish and the odd series terminates at x 3 :

a 1 ( x − 5 3 x 3 ) . (9.65)

The even series does not terminate. To obtain the polynomial, choose a 1 ≠ 0 , a 0 = 0 and normalize with P 3 ( 1 ) = 1 . Since the polynomial at x = 1 is a 1 ( 1 − 5 3 ) = − 2 3 a 1 ,

− 2 3 a 1 = 1 ⇒ a 1 = − 3 2 , (9.66)

so

P 3 ( x ) = − 3 2 ( x − 5 3 x 3 ) = 1 2 ( 5 x 3 − 3 x ) . (9.67)

Case ℓ = 4

Here ℓ ( ℓ + 1 ) = 20 . The even series is

a 0 [ 1 − 20 2 ! x 2 + 20 ( 2 ) ( 7 ) 4 ! x 4 − ⋯ ] = a 0 [ 1 − 10 x 2 + 35 3 x 4 − ⋯ ] . (9.68)

At n = 4 , the factor n ( n + 1 ) − ℓ ( ℓ + 1 ) = 20 − 20 = 0 , so higher even coefficients vanish and the even series terminates. The odd series does not terminate. Choose a 0 ≠ 0 , a 1 = 0 and normalize with P 4 ( 1 ) = 1 :

a 0 = 3 8 , (9.69)

giving

P 4 ( x ) = 1 8 ( 35 x 4 − 30 x 2 + 3 ) . (9.70)

Therefore Legendre Polynomials are

P 0 ( x ) = 1 , P 1 ( x ) = x , P 2 ( x ) = 1 2 ( 3 x 2 − 1 ) , P 3 ( x ) = 1 2 ( 5 x 3 − 3 x ) , P 4 ( x ) = 1 8 ( 35 x 4 − 30 x 2 + 3 ) , … (9.71)

These polynomials appear throughout physics, especially in problems involving spherical symmetry such as multipole expansions, potential theory, and quantum angular momentum.

Radius of Convergence and Interval of Validity

For large n ,

n ( n + 1 ) − ℓ ( ℓ + 1 ) ( n + 1 ) ( n + 2 ) ∼ n 2 n 2 = 1. (9.72)

Thus from

a n + 2 = n ( n + 1 ) − ℓ ( ℓ + 1 ) ( n + 1 ) ( n + 2 ) a n . (9.73)

we get

a n + 2 ∼ a n , for  n ≫ 1. (9.74)

This means that the coefficients behave like those of the geometric series

1 + x 2 + x 4 + ⋯ or x + x 3 + x 5 + ⋯ , (9.75)

both of which converge only when | x | < 1 .

This immediately gives

R = 1 (radius of convergence). (9.76)

Behavior at the endpoints.

At x = ± 1 , the general term behaves like

a 2 n ( ± 1 ) 2 n ∼ a 2 n , a 2 n + 1 ( ± 1 ) 2 n + 1 ∼ a 2 n + 1 , (9.77)

and since

a n + 2 ∼ a n , (9.78)

the terms do not tend to zero rapidly enough to converge. Typical endpoint behavior is of the form

1 + 1 3 + 1 5 + ⋯ , (9.79)

which diverges. Therefore,

the series solution diverges at  x = ± 1. (9.80)

Only when the series terminates—that is, when ℓ is a nonnegative integer—do we obtain a polynomial that is finite at the endpoints.

Interval of validity.

For non-terminating solutions,

y ( x ) = ∑ n = 0 ∞ a n x n is valid only for − 1 < x < 1. (9.81)

For terminating solutions (the Legendre polynomials P ℓ ( x ) ), the result is a finite polynomial of degree ℓ , so

P ℓ ( x )   is valid and finite on the entire interval  [ − 1 , 1 ] . (9.82)
Remark

In physical applications, x = cos ⁡ θ ranges over [ − 1 , 1 ] . Therefore only the terminating solutions—Legendre polynomials—are acceptable, while the second independent solution diverges at the endpoints.

Rodrigues’ Formula for Legendre Polynomials

Another elegant way of generating these polynomials is provided by Rodrigues’ formula.

TheoremRodrigues’ Formula
P ℓ ( x ) = 1 2 ℓ ℓ ! d ℓ d x ℓ ( x 2 − 1 ) ℓ (9.83)

This formula expresses the Legendre polynomial P ℓ ( x ) as the ℓ -th derivative of the simple algebraic function ( x 2 − 1 ) ℓ . It provides a direct computational method for generating all Legendre polynomials.

9.2.5Examples

Example1: Compute P 0 ( x ) from Rodrigues’ formula

For ℓ = 0 :

( x 2 − 1 ) 0 = 1 , d 0 d x 0 ( 1 ) = 1. (9.84)

Thus,

P 0 ( x ) = 1 2 0 0 ! ⋅ 1 = 1. (9.85)

P_0(x) = 1

This matches the known result.

Example2: Compute P 1 ( x ) from Rodrigues’ formula

For ℓ = 1 :

( x 2 − 1 ) 1 = x 2 − 1. (9.86)

Differentiate once:

d d x ( x 2 − 1 ) = 2 x . (9.87)

Now apply Rodrigues’ formula:

P 1 ( x ) = 1 2 1 1 ! ( 2 x ) = x . (9.88)

P_1(x) = x

Again this matches the standard Legendre polynomial.

Example3: Compute P 2 ( x ) from Rodrigues' formula

For ℓ = 2 :

( x 2 − 1 ) 2 = x 4 − 2 x 2 + 1. (9.89)

Differentiate twice:

d d x ( x 4 − 2 x 2 + 1 ) = 4 x 3 − 4 x , (9.90)
d 2 d x 2 ( x 4 − 2 x 2 + 1 ) = 12 x 2 − 4. (9.91)

Apply the normalization factor, noting that 2 2 2 ! = 4 ⋅ 2 = 8 :

P 2 ( x ) = 1 2 2 2 ! ( 12 x 2 − 4 ) = 1 8 ( 12 x 2 − 4 ) = 1 8 ⋅ 4 ( 3 x 2 − 1 ) = 1 2 ( 3 x 2 − 1 ) . (9.92)

P_2(x) = 12(3x^2 - 1)

Orthogonality

The Legendre polynomials satisfy an essential orthogonality relation on [ − 1 , 1 ] :

∫ − 1 1 P ℓ ( x ) P m ( x ) d x = 2 2 ℓ + 1 δ ℓ m . (9.93)
Remark

Orthogonality makes the Legendre polynomials a natural basis for expanding any sufficiently smooth function on [ − 1 , 1 ] . This is the spherical analogue of Fourier series.

9.2.8Generating Function

The Legendre polynomials have a remarkable generating function:

G ( x , t ) = 1 1 − 2 x t + t 2 = ∑ ℓ = 0 ∞ P ℓ ( x ) t ℓ . (9.94)

For any power series

f ( t ) = ∑ ℓ = 0 ∞ c ℓ t ℓ , (9.95)

we can recover the coefficients by

c ℓ = 1 ℓ ! d ℓ f d t ℓ | t = 0 . (9.96)

Here, x is treated as a constant parameter and t is the series variable. Applying this to the generating function,

G ( x , t ) = ∑ ℓ = 0 ∞ P ℓ ( x ) t ℓ , (9.97)

we get

P ℓ ( x ) = 1 ℓ ! ∂ ℓ ∂ t ℓ [ 1 1 − 2 x t + t 2 ] t = 0 . (9.98)
ExampleComputing the first few Legendre polynomials from G ( x , t )

(a) ℓ = 0 .

P 0 ( x ) = G ( x , 0 ) = 1 1 − 0 + 0 = 1. (9.99)

(b) ℓ = 1 . First derivative:

∂ G ∂ t = ∂ ∂ t ( 1 − 2 x t + t 2 ) − 1 / 2 = − 1 2 ( 1 − 2 x t + t 2 ) − 3 / 2 ( − 2 x + 2 t ) = ( x − t ) ( 1 − 2 x t + t 2 ) − 3 / 2 . (9.100)

Evaluate at t = 0 :

P 1 ( x ) = ∂ G ∂ t | t = 0 = x . (9.101)

(c) ℓ = 2 . Second derivative:

P 2 ( x ) = 1 2 ! ∂ 2 G ∂ t 2 | t = 0 . (9.102)

Carrying out the differentiation (or using a CAS) gives

P 2 ( x ) = 1 2 ( 3 x 2 − 1 ) . (9.103)

(d) ℓ = 3 .

P 3 ( x ) = 1 3 ! ∂ 3 G ∂ t 3 | t = 0 = 1 2 ( 5 x 3 − 3 x ) . (9.104)

Thus the generating function indeed reproduces the familiar Legendre polynomials:

P 0 ( x ) = 1 , P 1 ( x ) = x , P 2 ( x ) = 1 2 ( 3 x 2 − 1 ) , P 3 ( x ) = 1 2 ( 5 x 3 − 3 x ) ,   … (9.105)

9.3Associated Legendre Functions

The associated Legendre functions arise naturally when solving Laplace’s equation or the angular part of the Schrödinger equation in spherical coordinates. They generalize the Legendre polynomials by introducing an integer parameter m that accounts for the dependence on the azimuthal angle ϕ .

9.3.1Differential Equation

Starting from separation of variables on the sphere, the angular function P ℓ m ( x ) satisfies the associated Legendre differential equation

( 1 − x 2 ) y ″ − 2 x y ′ + [ ℓ ( ℓ + 1 ) − m 2 1 − x 2 ] y = 0 , − 1 ≤ x ≤ 1 , (9.106)

where

ℓ = 0 , 1 , 2 , … , m = 0 , 1 , 2 , … , ℓ . (9.107)

For m = 0 , the equation reduces to Legendre’s equation.

Remark

The points x = ± 1 are regular singular points. A Frobenius expansion shows that near x = ± 1 the solution behaves as ( 1 − x 2 ) m / 2 , which guarantees finiteness for integer m .

9.3.2Generating the Solutions

The associated Legendre functions can be obtained from the Legendre polynomials by repeated differentiation:

P ℓ m ( x ) = ( − 1 ) m ( 1 − x 2 ) m / 2 d m d x m P ℓ ( x ) . (9.108)

This formula produces all associated functions once P ℓ ( x ) is known.

Examples:

P 1 1 ( x ) = − ( 1 − x 2 ) 1 / 2 , P 2 1 ( x ) = − 3 x ( 1 − x 2 ) 1 / 2 , P 2 2 ( x ) = 3 ( 1 − x 2 ) . (9.109)
Remark

When m is even, P ℓ m ( x ) has the same parity as P ℓ ( x ) :

P ℓ m ( − x ) = ( − 1 ) ℓ + m P ℓ m ( x ) . (9.110)

9.3.3Orthogonality

For fixed m , the associated Legendre functions are orthogonal on [ − 1 , 1 ] :

∫ − 1 1 P ℓ m ( x ) P ℓ ′ m ( x ) d x = 2 ( ℓ + m ) ! ( 2 ℓ + 1 ) ( ℓ − m ) ! δ ℓ ℓ ′ . (9.111)

This extends the orthogonality of Legendre polynomials to functions of higher order m .

Remark

Because of this orthogonality, associated Legendre functions play the same role in spherical problems that sines and cosines play in problems with Cartesian symmetry.

9.3.4Connection to Spherical Harmonics

The full angular dependence of Laplace’s equation and the angular part of the Schrödinger equation in spherical coordinates is expressed using the spherical harmonics:

Y ℓ m ( θ , ϕ ) = N ℓ m P ℓ m ( cos ⁡ θ ) e i m ϕ , ℓ = 0 , 1 , 2 , … , m = − ℓ , … , ℓ . (9.112)

Normalization constant.

The spherical harmonics are orthonormal on the unit sphere,

∫ 0 2 π ∫ 0 π Y ℓ m ( θ , ϕ ) Y ℓ ′ m ′ ∗ ( θ , ϕ ) sin ⁡ θ d θ d ϕ = δ ℓ ℓ ′ δ m m ′ . (9.113)

This is achieved when

N ℓ m = ( − 1 ) m 2 ℓ + 1 4 π ( ℓ − m ) ! ( ℓ + m ) ! . (9.114)

The factor ( − 1 ) m (the Condon–Shortley phase) is conventional and ensures consistency with standard quantum mechanics notation.

RemarkPhysical meaning

  • Each pair ( ℓ , m ) labels an angular momentum eigenstate.

  • P ℓ m ( cos ⁡ θ ) describes the dependence on the polar angle θ .

  • e i m ϕ carries the azimuthal dependence and corresponds to the z -component of angular momentum.

  • Higher | m | values push the probability toward the equator ( θ = π / 2 ), reflecting the classical picture of a rotating object with greater projection of angular momentum about the z -axis.

Thus, the associated Legendre functions provide the essential angular structure of all spherical harmonics.

9.4Bessel’s Differential Equation

Bessel’s equation appears naturally in problems with cylindrical symmetry: heat conduction in cylinders, vibrations of circular membranes (“drumhead problem”), electromagnetic waves in cylindrical waveguides, and quantum mechanics in cylindrical potentials.

The Bessel differential equation of order p is

x 2 y ″ + x y ′ + ( x 2 − p 2 ) y = 0 , p ∈ R . (9.115)
Remark

The point x = 0 is a regular singular point. Therefore we must use the Frobenius method (generalized power series). For x > 0 , all coefficients are analytic and the equation is perfectly regular.

9.4.1Frobenius Series Solution About x = 0 (Regular Singular Point)

We seek a generalized power series (Frobenius expansion)

y ( x ) = ∑ n = 0 ∞ a n x n + r , a 0 ≠ 0 , (9.116)

where the exponent r is to be determined.

Compute derivatives:

y ′ = ∑ n = 0 ∞ ( n + r ) a n x n + r − 1 , y ″ = ∑ n = 0 ∞ ( n + r ) ( n + r − 1 ) a n x n + r − 2 . (9.117)

Substitute into Bessel’s equation:

x 2 y ″ + x y ′ + ( x 2 − p 2 ) y = 0. (9.118)

We obtain:

x 2 ∑ n = 0 ∞ ( n + r ) ( n + r − 1 ) a n x n + r − 2 + x ∑ n = 0 ∞ ( n + r ) a n x n + r − 1 + ( x 2 − p 2 ) ∑ n = 0 ∞ a n x n + r = 0. (9.119)

Simplifying each term:

∑ n = 0 ∞ ( n + r ) ( n + r − 1 ) a n x n + r + ∑ n = 0 ∞ ( n + r ) a n x n + r + ∑ n = 0 ∞ a n x n + r + 2 − p 2 ∑ n = 0 ∞ a n x n + r = 0. (9.120)

Combine the first three sums:

( n + r ) ( n + r − 1 ) + ( n + r ) − p 2 = ( n + r ) 2 − p 2 . (9.121)

Thus,

∑ n = 0 ∞ [ ( n + r ) 2 − p 2 ] a n x n + r + ∑ n = 0 ∞ a n x n + r + 2 = 0. (9.122)

Shift the index in the x n + r + 2 term. Starting from

∑ n = 0 ∞ a n x n + r + 2 , (9.123)

let m = n + 2 (so n = m − 2 ). Then

∑ n = 0 ∞ a n x n + r + 2 = ∑ m = 2 ∞ a m − 2 x m + r . (9.124)

Renaming the index m → n gives

∑ n = 0 ∞ [ ( n + r ) 2 − p 2 ] a n x n + r + ∑ n = 2 ∞ a n − 2 x n + r = 0. (9.125)

Now all powers of x match:

( r 2 − p 2 ) a 0 x r + [ ( 1 + r ) 2 − p 2 ] a 1 x r + 1 + ∑ n = 2 ∞ [ ( ( n + r ) 2 − p 2 ) a n + a n − 2 ] x n + r = 0. (9.126)

Because this holds for all x , each coefficient must vanish:

  • Indicial equation (coefficient of x r ):

    ( r 2 − p 2 ) a 0 = 0 ⇒ r = ± p . (9.127)

    We assume a 0 ≠ 0 , so the equation determines r .

  • Coefficient of x r + 1 :

    [ ( 1 + r ) 2 − p 2 ] a 1 = 0. (9.128)

    For r = ± p , the factor is nonzero, so we must have

    a 1 = 0 . (9.129)

    Thus the series built from a 0 contains only even powers of x .

  • Recurrence relation for n ≥ 2 (coefficient of x n + r ):

    ( ( n + r ) 2 − p 2 ) a n + a n − 2 = 0 ⇒ a n = − a n − 2 ( n + r ) 2 − p 2 . (9.130)

To obtain a solution that stays finite at x = 0 , we choose the positive root r = p . Then the recurrence becomes

a n = − a n − 2 ( n + p ) 2 − p 2 = − a n − 2 n ( n + 2 p ) . (9.131)

Since a 1 = 0 , all odd coefficients are zero. We therefore write n = 2 k (even index) and obtain

a 2 k = − a 2 k − 2 ( 2 k + p ) 2 − p 2 = − a 2 k − 2 2 k ( 2 k + 2 p ) = − a 2 k − 2 2 2 k ( k + p ) . ( ⋆ )

Gamma Function and Coefficient Formula

DefinitionGamma Function

For Re ( z ) > 0 , the Gamma function is defined by

Γ ( z ) = ∫ 0 ∞ t z − 1 e − t d t . (9.132)

It satisfies the recursion

Γ ( z + 1 ) = z Γ ( z ) , (9.133)

and in particular, for a positive integer n ,

Γ ( n + 1 ) = n ! . (9.134)

We now use the recurrence ( ⋆ ) to write the first few even coefficients in a systematic way.

For k = 1 :

a 2 = − a 0 2 2 1 ( 1 + p ) = − a 0 2 2 ( 1 + p ) = − a 0 Γ ( 1 + p ) 2 2 Γ ( 2 + p ) . (9.135)

For k = 2 :

a 4 = − a 2 2 2 2 ( 2 + p ) = a 0 2 4 2 ! ( 1 + p ) ( 2 + p ) = a 0 Γ ( 1 + p ) 2 4 2 ! Γ ( 3 + p ) . (9.136)

For k = 3 :

a 6 = − a 4 2 2 3 ( 3 + p ) = − a 0 2 6 3 ! ( 1 + p ) ( 2 + p ) ( 3 + p ) = − a 0 Γ ( 1 + p ) 2 6 3 ! Γ ( 4 + p ) . (9.137)

We see the pattern: each new a 2 k picks up a factor − 1 / [ 2 2 k ( k + p ) ] , which builds up the factorials and Gamma functions.

By induction, the general even coefficient is

a 2 k = ( − 1 ) k a 0 Γ ( 1 + p ) 2 2 k k ! Γ ( k + 1 + p ) , k = 0 , 1 , 2 , … ( † )

(For k = 0 this gives a 0 back.)

Constructing the Series Solution

Our Frobenius ansatz was

y ( x ) = ∑ n = 0 ∞ a n x n + r , r = p . (9.138)

Since only even n survive,

y ( x ) = ∑ k = 0 ∞ a 2 k x 2 k + p . (9.139)

Insert the general coefficient ( † ):

y ( x ) = ∑ k = 0 ∞ ( − 1 ) k a 0 Γ ( 1 + p ) 2 2 k k ! Γ ( k + 1 + p ) x 2 k + p = a 0 Γ ( 1 + p ) x p ∑ k = 0 ∞ ( − 1 ) k k ! Γ ( k + 1 + p ) ( x 2 2 2 ) k = a 0 Γ ( 1 + p ) ∑ k = 0 ∞ ( − 1 ) k k ! Γ ( k + 1 + p ) ( x 2 ) 2 k + p . (9.140)

So

y ( x ) = a 0 Γ ( 1 + p ) ∑ k = 0 ∞ ( − 1 ) k k ! Γ ( k + p + 1 ) ( x 2 ) 2 k + p . (9.141)

To obtain the standard Bessel function of the first kind J p ( x ) , we choose a 0 so that the prefactor becomes 1. A convenient choice is

a 0 = 1 2 p Γ ( 1 + p ) . (9.142)

Then

a 0 Γ ( 1 + p ) = 1 2 p , (9.143)

and we arrive at the final series:

J p ( x ) = ∑ k = 0 ∞ ( − 1 ) k k ! Γ ( k + p + 1 ) ( x 2 ) 2 k + p , (9.144)

and the second solution is given by J − p ( x )

The First Solution for Integer Order

For integer order p = n , the general series reduces to

J n ( x ) = ∑ k = 0 ∞ ( − 1 ) k k ! ( n + k ) ! ( x 2 ) 2 k + n (9.145)

since Γ ( n + k + 1 ) = ( n + k ) ! . This is the standard power–series definition of the Bessel function of the first kind. Small-order Bessel functions follow immediately:

J 0 ( x ) = 1 − x 2 4 + x 4 64 − x 6 2304 + ⋯ , J 1 ( x ) = x 2 − x 3 16 + x 5 384 − x 7 18432 + ⋯ , J 2 ( x ) = x 2 8 − x 4 96 + x 6 3072 − ⋯ . (9.146)

The Second Solution for Integer Order

For integer p = n we have the symmetry relation

J − n ( x ) = ( − 1 ) n J n ( x ) , (9.147)

which shows that J n and J − n are not linearly independent when n is an integer. To obtain a second linearly independent solution, we define

Y p ( x ) = J p ( x ) cos ⁡ ( p π ) − J − p ( x ) sin ⁡ ( p π ) , (9.148)

which is well-defined for all non-integer p . In the limit as p → n ∈ Z , this expression produces the Bessel function of the second kind, often denoted Y n ( x ) or N n ( x ) .

Near the origin, Y n ( x ) diverges logarithmically:

Y n ( x ) ∼ 2 π [ ln ( x 2 ) + γ ] J n ( x ) + ⋯ , x → 0 , (9.149)

where γ is the Euler–Mascheroni constant.

RemarkPhysical acceptability

In most problems involving cylindrical symmetry (vibrating membranes, heat flow in cylinders, electromagnetic waves in cylindrical guides), the solution must remain finite at the origin. Since

Y p ( x ) → ∞ as  x → 0 , (9.150)

the only physically acceptable solution is

J p ( x ) . (9.151)

9.4.6Hankel Functions (Bessel Functions of the Third Kind)

The Bessel functions of the first and second kind, J p ( x ) and Y p ( x ) , form a fundamental pair of real solutions to Bessel’s differential equation. In many applications—especially those involving wave propagation, radiation, or scattering—it is convenient to combine these into complex-valued solutions known as the Hankel functions.

DefinitionHankel Functions of Order p

The Hankel functions of the first and second kind are defined as

H p ( 1 ) ( x ) = J p ( x ) + i Y p ( x ) , H p ( 2 ) ( x ) = J p ( x ) − i Y p ( x ) . (9.152)

The functions H p ( 1 ) ( x ) and H p ( 2 ) ( x ) are linearly independent and form a complete pair of complex solutions to Bessel’s equation:

x 2 y ″ + x y ′ + ( x 2 − p 2 ) y = 0. (9.153)

9.4.7Graphical Behavior of Bessel Functions

To better understand the qualitative behavior of Bessel functions, it is useful to look at their graphs. Figure 9.2 shows the first three Bessel functions of the first kind, J 0 ( x ) , J 1 ( x ) , and J 2 ( x ) , and Fig. 9.3 shows the corresponding Bessel functions of the second kind, Y 0 ( x ) , Y 1 ( x ) , and Y 2 ( x ) , all plotted for 0 < x ≤ 20 .

RemarkBessel functions of the first kind J α ( x )

  • J 0 ( x ) starts from J 0 ( 0 ) = 1 ; all higher orders satisfy J n ( 0 ) = 0 for n ≥ 1 .

  • Each J α ( x ) oscillates with a wavelength that slowly approaches a constant as x increases.

  • The oscillations have a slowly decreasing amplitude, roughly decaying like 1 / x for large x .

  • The zeros of J α ( x ) are not equally spaced, but they become more nearly equally spaced as x grows.

  • Higher orders J 1 ( x ) , J 2 ( x ) , … are “pushed to the right’’: they remain small near the origin and their first zero occurs at larger values of x .

RemarkBessel functions of the second kind Y α ( x )

  • Near the origin, all Y α ( x ) have a logarithmic singularity and diverge to − ∞ as x → 0 + .

  • For x away from zero, Y α ( x ) oscillate with a behavior similar to J α ( x ) : approximately sinusoidal with a slowly decreasing amplitude for large x .

  • Because of the divergence at x = 0 , Y α ( x ) are usually not acceptable in physical problems where the solution must remain finite at the origin (for example, in cylindrical coordinates with a physical axis at r = 0 ).

  • Nevertheless, Y α ( x ) form, together with J α ( x ) , a complete set of independent solutions of Bessel’s equation on ( 0 , ∞ ) .

9.4.8Orthogonality

On the interval 0 ≤ x ≤ R , the Bessel functions satisfy

∫ 0 R x J p ( α p m x R ) J p ( α p n x R ) d x = R 2 2 [ J p + 1 ( α p n ) ] 2 δ m n , (9.154)

where α p n are the zeros of J p ( x ) .

Remark

This orthogonality makes Bessel functions the natural basis for expanding functions defined on circular domains, just as Legendre polynomials are the natural basis on [ − 1 , 1 ] .

9.4.9Generating Function

The Bessel functions have the elegant generating function

e x 2 ( t − 1 t ) = ∑ n = − ∞ ∞ t n J n ( x ) . (9.155)
Example

Expanding for small t yields

e x 2 ( t − 1 t ) = J 0 ( x ) + t J 1 ( x ) + t 2 J 2 ( x ) + ⋯ + t − 1 J − 1 ( x ) + t − 2 J − 2 ( x ) + ⋯ . (9.156)

Differentiating with respect to t and evaluating at t = 0 (or ∞ ) extracts J n ( x ) in the same manner as with Legendre polynomials.

9.5Orthogonal Eigenfunction Bases in Physics

We have learned that many important families of functions form orthogonal and complete bases. This means that any physically meaningful function can be expanded using these basis functions, and the expansion coefficients follow directly from their orthogonality relations.

In this section we summarize three of the most important bases encountered in mathematical physics:

Fourier series modes  e i k n x , Legendre polynomials  P ℓ ( x ) , Spherical harmonics  Y ℓ m ( θ , ϕ ) . (9.157)

9.5.11. Fourier Series Modes e i k n x : Basis on a Finite Interval

On the interval [ − L 2 , L 2 ] , the complex Fourier basis functions are

e i k n x , k n = 2 π n L , n = 0 , ± 1 , ± 2 , … (9.158)
TheoremOrthogonality of the Fourier series basis
∫ − L / 2 L / 2 e i k n x e − i k m x d x = L δ n m . (9.159)

Thus any function f ( x ) defined on [ − L 2 , L 2 ] can be expanded as a Fourier series:

f ( x ) = ∑ n = − ∞ ∞ c n e i k n x . (9.160)

Using orthogonality, the expansion coefficients are

c n = 1 L ∫ − L / 2 L / 2 f ( x ) e − i k n x d x . (9.161)

Therefore, the set { e i k n x } forms a complete orthogonal basis on [ − L 2 , L 2 ] .

9.5.22. Legendre Polynomials P ℓ ( x ) : Basis on [ − 1 , 1 ]

When the problem depends only on an angular variable through x = cos ⁡ θ , the relevant basis functions are the Legendre polynomials:

P 0 ( x ) , P 1 ( x ) , P 2 ( x ) , … , − 1 ≤ x ≤ 1. (9.162)
TheoremOrthogonality relation
∫ − 1 1 P ℓ ( x ) P ℓ ′ ( x ) d x = 2 2 ℓ + 1 δ ℓ ℓ ′ . (9.163)

A function f ( x ) defined on [ − 1 , 1 ] can be expanded as

f ( x ) = ∑ ℓ = 0 ∞ c ℓ P ℓ ( x ) , (9.164)

with coefficients obtained from orthogonality:

c ℓ = 2 ℓ + 1 2 ∫ − 1 1 f ( x ) P ℓ ( x ) d x . (9.165)

Thus { P ℓ ( x ) } forms a complete orthogonal basis on [ − 1 , 1 ] .

9.5.33. Spherical Harmonics Y ℓ m ( θ , ϕ ) : Basis on the Sphere

For functions defined on the sphere, the natural basis is the set of spherical harmonics:

Y ℓ m ( θ , ϕ ) , ℓ = 0 , 1 , 2 , … , m = − ℓ , … , ℓ . (9.166)
TheoremOrthogonality relation
∫ 0 2 π ∫ 0 π Y ℓ m ( θ , ϕ ) Y ℓ ′ m ′ ∗ ( θ , ϕ ) sin ⁡ θ d θ d ϕ = δ ℓ ℓ ′ δ m m ′ . (9.167)

Any square-integrable function on the sphere can be expanded as

f ( θ , ϕ ) = ∑ ℓ = 0 ∞ ∑ m = − ℓ ℓ c ℓ m Y ℓ m ( θ , ϕ ) , (9.168)

with expansion coefficients

c ℓ m = ∫ 0 2 π ∫ 0 π f ( θ , ϕ ) Y ℓ m ∗ ( θ , ϕ ) sin ⁡ θ d θ d ϕ . (9.169)

Thus { Y ℓ m } forms a complete orthonormal basis on the sphere S 2 .

9.6Where Series Solutions Are Used

The elementary methods of Chapter 8 fail the moment an ODE has variable coefficients, and almost every equation coming from a physical problem with spherical or cylindrical symmetry does. The power-series and Frobenius methods of this chapter are what handle them, and the special functions they produce — Legendre polynomials, Bessel functions, spherical harmonics — are not curiosities but the standard vocabulary of mathematical physics.

  • Spherical problems. Separating Laplace's equation or the Schrödinger equation in spherical coordinates always produces Legendre's equation for the polar angle. Its finite solutions are the Legendre polynomials, and combined with e i m ϕ they build the spherical harmonics Y ℓ m — the angular states of the hydrogen atom and the shapes behind the periodic table.

  • Cylindrical problems. Separating the wave or heat equation in cylindrical coordinates produces Bessel's equation. Bessel functions describe the vibrations of a circular drum, the modes of an optical fibre or waveguide, and diffraction through a circular aperture.

  • Multipole expansions. The generating function 1 / 1 − 2 x t + t 2 = ∑ P ℓ ( x ) t ℓ is exactly the expansion of a Coulomb or gravitational potential in powers of distance ratio, term by term the monopole, dipole, quadrupole, and so on.

  • Orthogonal expansions. Because each family is orthogonal and complete, an arbitrary function can be expanded in it and the coefficients read off by an integral — the same move as a Fourier series (Chapter 7), extended to the interval [ − 1 , 1 ] and to the sphere.

  • Quantum angular momentum. The pair ( ℓ , m ) labelling the spherical harmonics is precisely the angular-momentum quantum numbers, and the orthogonality relation is the statement that distinct angular-momentum states do not overlap.

Remark

One structural idea ties the chapter together. Where a solution is required, an ordinary point admits an ordinary power series; a regular singular point requires the Frobenius form x r ∑ a n x n with r fixed by the indicial equation; an irregular singular point generally admits neither. Legendre ( x = 0 ordinary) and Bessel ( x = 0 regular singular) are the two worked cases, and the physically admissible solutions are singled out by demanding finiteness at the singular points — which is exactly what forces ℓ to be an integer and picks J p over Y p .
