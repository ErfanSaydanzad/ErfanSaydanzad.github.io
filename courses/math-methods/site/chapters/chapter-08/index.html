Ordinary Differential Equations

8.1Introduction and General Form

An ordinary differential equation (ODE) is an equation that relates a function y ( x ) to its derivatives with respect to a single independent variable x :

F ( x , y , d y d x , d 2 y d x 2 , … , d n y d x n ) = 0. (8.1)
Example - Second-order ordinary differential equation
x 2 d 2 y d x 2 + 3 x d y d x + y = 0. (8.2)
Definition - Basic Terminology for ODEs

  • Order of an ODE: The order of a differential equation is the highest derivative that appears in the equation.

    d 3 y d x 3 + 2 d y d x = 0 ⇒ Order = 3 (8.3)

  • Degree of an ODE: The degree of a differential equation is the exponent of the highest-order derivative, provided the equation is polynomial in derivatives.

    ( d 2 y d x 2 ) 3 + d y d x = 0 ⇒ Degree = 3 (8.4)

  • Solution of an ODE: A function y ( x ) that satisfies the differential equation for all x in a given interval.

    d y d x = 2 x ⇒ y = x 2 + C (8.5)

8.2Classification of ODEs

Ordinary differential equations (ODEs) can be classified according to several characteristics. The most fundamental distinction is between linear and nonlinear equations.

Linear vs. Nonlinear ODEs

An ODE is called linear if the dependent variable y and all its derivatives appear only to the first power and are not multiplied or composed with each other. The general n th -order linear ODE can be written as

a n ( x ) y ( n ) + a n − 1 ( x ) y ( n − 1 ) + ⋯ + a 1 ( x ) y ′ + a 0 ( x ) y = f ( x ) , (8.6)

where a i ( x ) and f ( x ) are known functions of the independent variable x .

If any term involves products or nonlinear functions of y or its derivatives (such as y 2 , y y ′ , or sin ⁡ y ), the equation is said to be nonlinear.

Example
Linear: y ″ + 3 y ′ + 2 y = sin ⁡ x , Nonlinear: y ″ + y y ′ = 0.
Remark

Linear ODEs are generally easier to solve because they obey the principle of superposition, if y 1 and y 2 are solutions, then any linear combination C 1 y 1 + C 2 y 2 is also a solution. Nonlinear ODEs, on the other hand, can exhibit far richer behavior, such as limited analytic solvability, sensitivity to initial conditions, or even chaotic motion. However, certain first-order nonlinear equations, such as separable or Bernoulli equations, can still be solved analytically.

Classification of Linear ODEs

Once an equation is identified as linear, we can further classify it based on its right-hand side and coefficients.

  • Homogeneous Linear ODE: The right-hand side equals zero,

    a n ( x ) y ( n ) + a n − 1 ( x ) y ( n − 1 ) + ⋯ + a 0 ( x ) y = 0. (8.7)

    In this case, every term involves y or its derivatives, and the trivial solution y = 0 always satisfies the equation. The general solution typically involves n arbitrary constants determined by initial or boundary conditions.

  • Nonhomogeneous Linear ODE: The right-hand side is a nonzero function f ( x ) ,

    a n ( x ) y ( n ) + a n − 1 ( x ) y ( n − 1 ) + ⋯ + a 0 ( x ) y = f ( x ) . (8.8)

    The general solution is the sum of two parts:

    y ( x ) = y h ( x ) + y p ( x ) , (8.9)

    where y h is the general solution of the corresponding homogeneous equation and y p is a particular solution to the full nonhomogeneous equation.

  • Linear ODEs with Constant Coefficients: When the coefficients a i are constants rather than functions of x ,

    a n y ( n ) + a n − 1 y ( n − 1 ) + ⋯ + a 1 y ′ + a 0 y = f ( x ) , (8.10)

    the equation becomes especially important in physics and engineering. Such forms describe systems like simple harmonic oscillators, RC and RL circuits, and exponential decay processes.

8.3First-Order ODEs

A first-order ODE involves only the first derivative of the unknown function:

d y d x = f ( x , y ) . (8.11)

This general form can represent both linear and nonlinear cases, depending on how f ( x , y ) depends on y . Such equations appear widely in physics—for example, in modeling exponential decay, population growth, or motion with velocity-dependent forces.

8.3.1Separable Equations

A first-order ODE is called separable if it can be expressed as

d y d x = g ( x ) h ( y ) , (8.12)

where the function on the right-hand side is the product of a function of x and a function of y . Although separable equations are often nonlinear, they are still analytically solvable because the variables can be separated.

Rearranging terms gives

d y h ( y ) = g ( x ) d x , (8.13)

and integrating both sides yields

∫ d y h ( y ) = ∫ g ( x ) d x . (8.14)
Example - Solve the differential equation
d y d x = x y . (8.15)

Solution.

Step 1. Recognize the type of equation. This is a first-order separable (and also linear) differential equation.

Step 2. Separate the variables.

d y y = x d x . (8.16)

Step 3. Integrate both sides.

∫ 1 y d y = ∫ x d x ⟹ ln ⁡ | y | = x 2 2 + C . (8.17)

Step 4. Simplify the result. Exponentiate both sides:

y = e C e x 2 / 2 . (8.18)

Let C 1 = e C (a new arbitrary constant). Then

y ( x ) = C 1 e x 2 / 2 . (8.19)

Step 5. Verification. Differentiate y = C 1 e x 2 / 2 :

d y d x = C 1 x e x 2 / 2 = x y , (8.20)

confirming that the solution satisfies the ODE.

Example - Solve the differential equation
x d y d x = y + 1. (8.21)

Solution.

Step 1. Separate the variables. Divide both sides by x ( y + 1 ) :

1 y + 1 d y d x = 1 x ⟹ d y y + 1 = d x x . (8.22)

Step 2. Integrate both sides.

∫ d y y + 1 = ∫ d x x ⟹ ln ⁡ | y + 1 | = ln ⁡ | x | + C . (8.23)

Step 3. Simplify the constant. Let C = ln ⁡ a (for a > 0 ) to combine logarithms conveniently:

ln ⁡ | y + 1 | = ln ⁡ | a x | . (8.24)

Step 4. Remove the logarithms.

| y + 1 | = a | x | . (8.25)

Because a can absorb the sign, we write simply

y + 1 = a x , a  constant . (8.26)

Step 5. Interpretation. The general solution

y = a x − 1 (8.27)

represents a family of straight lines in the ( x , y ) -plane, one line for each value of the constant a . Selecting a particular value of a determines a single specific curve from this family.

Example - Solve the differential equation
d y d x = 1 − y 2 . (8.28)

Find the particular solutions satisfying (a) x = 0 , y = 0 and (b) x = 0 , y = 1 , and discuss any solutions not obtained by separation.

Step 1. Separation of variables and integration. For | y | < 1 , the equation can be written in separable form:

d y 1 − y 2 = d x . (8.29)

Integrating both sides gives

arcsin ⁡ ( y ) = x + α , (8.30)

so the general solution (valid where | y | < 1 ) is

y ( x ) = sin ⁡ ( x + α ) . (8.31)

Step 4. Particular solutions.

(a) y ( 0 ) = 0 : From arcsin ⁡ y = x + α , substituting x = 0 , y = 0 gives α = 0 or π . Because y ′ ≥ 0 , we take the increasing branch:

8.3.2Linear First-Order Equations

A linear first-order equation has the form

d y d x + P ( x ) y = Q ( x ) . (8.38)

Integrating Factor Method:

  1. Compute the integrating factor:

    μ ( x ) = e ∫ P ( x ) d x . (8.39)

  2. Multiply through by μ ( x ) :

    d d x ( μ ( x ) y ) = μ ( x ) Q ( x ) . (8.40)

  3. Integrate:

    μ ( x ) y = ∫ μ ( x ) Q ( x ) d x . (8.41)

  4. Solve for y ( x ) :

    y = [ μ ( x ) ] − 1 ∫ μ ( x ) Q ( x ) d x . (8.42)
Example - Solve the first-order linear ODE
y ′ + 2 y = e − x . (8.43)

Solution.

Step 1. Identify P ( x ) and Q ( x ) . The equation is in the standard linear form

y ′ + P ( x ) y = Q ( x ) , (8.44)

where

P ( x ) = 2 , Q ( x ) = e − x . (8.45)

Step 2. Compute the integrating factor. The integrating factor is

μ ( x ) = e ∫ P ( x ) d x = e ∫ 2 d x = e 2 x . (8.46)

Step 3. Apply the general solution formula.

y = [ μ ( x ) ] − 1 ∫ μ ( x ) Q ( x ) d x . (8.47)

Substitute μ ( x ) = e 2 x and Q ( x ) = e − x :

y = e − 2 x ∫ e 2 x e − x d x = e − 2 x ∫ e x d x . (8.48)

Step 4. Evaluate the integral.

y = e − 2 x ( e x + C ) = e − x + C e − 2 x . (8.49)

Final Answer:

y = e − x + C e − 2 x . (8.50)

Verification. Substitute y = e − x + C e − 2 x into the original equation:

y ′ = − e − x − 2 C e − 2 x , ⇒ y ′ + 2 y = ( − e − x − 2 C e − 2 x ) + 2 ( e − x + C e − 2 x ) = e − x , (8.51)

which satisfies the ODE.

Separable equations and linear equations are the two types of first-order equations most commonly encountered in basic applications. However, there exist several other important forms of first-order equations that can be transformed into solvable types. In this section, we briefly introduce two such forms: the Bernoulli equation and exact equations. More details and applications are found in advanced differential equations texts.

8.3.4The Bernoulli Equation

The differential equation

y ′ + P ( x ) y = Q ( x ) y n , (8.52)

where P ( x ) and Q ( x ) are known functions of x , is called the Bernoulli equation. It is nonlinear for n ≠ 0 , 1 , but it can be transformed into a linear equation through an appropriate substitution.

Step 1. Multiply by y − n .

y − n y ′ + P ( x ) y 1 − n = Q ( x ) . (8.53)

Step 2. Simplify using the substitution z = y 1 − n .

d z d x = ( 1 − n ) y − n y ′ . (8.54)

Hence, y − n y ′ = 1 1 − n z ′ . Substitute this into the previous equation:

1 1 − n z ′ + P ( x ) z = Q ( x ) . (8.55)

Step 3. Multiply through by ( 1 − n ) to simplify.

z ′ + ( 1 − n ) P ( x ) z = ( 1 − n ) Q ( x ) . (8.56)

This is now a first-order linear ODE in z ( x ) , which can be solved using the integrating factor method.

Reduced linear form: z' + (1-n)P(x)z = (1-n)Q(x).

After solving for z ( x ) , the original dependent variable is recovered via

y = z 1 1 − n . (8.57)
Remark

The Bernoulli equation provides an important link between nonlinear and linear first-order ODEs. By multiplying through by y − n and substituting z = y 1 − n , we convert a nonlinear equation into a solvable linear form. This transformation frequently appears in problems involving population dynamics, exponential growth and decay, and fluid motion.

Example - Reduce to linear form and solve
y ′ + y = x y 2 / 3 . (8.58)

Solution.

Step 1. Multiply by y − n with n = 2 3 .

y − 2 / 3 y ′ + y 1 / 3 = x . (8.59)

Step 2. Let z = y 1 − n = y 1 / 3 . Then z ′ = 1 3 y − 2 / 3 y ′ , so y − 2 / 3 y ′ = 3 z ′ . Substitute:

3 z ′ + z = x ⟹ z ′ + 1 3 z = 1 3 x . (8.60)

Step 3. Solve the linear equation using the integrating-factor formula. For

z ′ + p ( x ) z = q ( x ) , p ( x ) = 1 3 , q ( x ) = 1 3 x , (8.61)

the integrating factor is μ ( x ) = e ∫ p ( x ) d x = e x / 3 . Apply

z = [ μ ( x ) ] − 1 ∫ μ ( x ) q ( x ) d x : (8.62)
z = e − x / 3 [ ∫ e x / 3 ⋅ 1 3 x d x + C ] = e − x / 3 [ e x / 3 ( x − 3 ) + C ] = x − 3 + C e − x / 3 . (8.63)

Step 4. Back–substitute to y . Since z = y 1 / 3 ,

y ( x ) = ( x − 3 + C e − x / 3 ) 3 . (8.64)

Step 5. Singular solution. Because y 2 / 3 ≥ 0 for all real y , the constant function

y ( x ) ≡ 0 (8.65)

also satisfies the original ODE. Thus the complete set consists of the one-parameter family above together with y ≡ 0 .

8.3.5Exact Differential Equations

A general first-order differential equation can often be written in the form

M ( x , y ) d x + N ( x , y ) d y = 0 , (8.66)

where M and N are functions of two variables x and y .

Definition - Exact Differential Equation

The first–order differential equation

M ( x , y ) d x + N ( x , y ) d y = 0 (8.67)

is called exact if there exists a scalar function U ( x , y ) (called a potential function) such that

d U ( x , y ) = M ( x , y ) d x + N ( x , y ) d y , where  M = ∂ U ∂ x , N = ∂ U ∂ y . (8.68)

In this case, the general solution can be written implicitly as

U ( x , y ) = C . (8.69)

A necessary and sufficient condition for exactness (assuming continuous partial derivatives) is

∂ M ∂ y = ∂ N ∂ x . (8.70)
Remark

The condition above ensures that the mixed second derivatives of U ( x , y ) are equal:

∂ 2 U ∂ x ∂ y = ∂ 2 U ∂ y ∂ x . (8.71)

This is guaranteed by Clairaut’s theorem when M and N have continuous partial derivatives.

Solution Procedure:

  1. Check whether ∂ M ∂ y = ∂ N ∂ x . If true, the equation is exact.

  2. Integrate M ( x , y ) with respect to x , treating y as constant:

    U ( x , y ) = ∫ M ( x , y ) d x + F ( y ) , (8.72)

    where F ( y ) is an arbitrary function of y .

  3. Since U ( x , y ) must satisfy

    N ( x , y ) = ∂ U ∂ y , (8.73)

    we differentiate the above expression for U ( x , y ) with respect to y :

    ∂ U ∂ y = ∂ ∂ y ( ∫ M ( x , y ) d x ) + F ′ ( y ) . (8.74)

    Now substitute the known expression for N ( x , y ) from the original equation and equate:

    N ( x , y ) = ∂ ∂ y ( ∫ M ( x , y ) d x ) + F ′ ( y ) . (8.75)

    From this, we can solve for F ′ ( y ) :

    F ′ ( y ) = N ( x , y ) − ∂ ∂ y ( ∫ M ( x , y ) d x ) . (8.76)

    Integrate with respect to y to find F ( y ) , and then write the final expression for U ( x , y ) . The general solution is obtained from

    U ( x , y ) = constant. (8.77)

  4. Integrate F ′ ( y ) to find F ( y ) , substitute back, and write the final solution U ( x , y ) = C .

Example - Solving an Exact Differential Equation

Solve

( 2 x y + y 3 ) d x + ( x 2 + 3 x y 2 ) d y = 0. (8.78)

Solution.

Step 1. Identify

M ( x , y ) = 2 x y + y 3 , N ( x , y ) = x 2 + 3 x y 2 . (8.79)

Step 2. Check the exactness condition:

∂ M ∂ y = 2 x + 3 y 2 , ∂ N ∂ x = 2 x + 3 y 2 . (8.80)

They are equal, so the equation is exact.

Step 3. Integrate M ( x , y ) with respect to x :

U ( x , y ) = ∫ ( 2 x y + y 3 ) d x = x 2 y + x y 3 + F ( y ) . (8.81)

Step 4. Differentiate with respect to y :

∂ U ∂ y = x 2 + 3 x y 2 + F ′ ( y ) . (8.82)

Compare with N ( x , y ) = x 2 + 3 x y 2 , which implies F ′ ( y ) = 0 .

Step 5. Hence F ( y ) = constant . The potential function is

U ( x , y ) = x 2 y + x y 3 . (8.83)

Step 6. The general solution is

x 2 y + x y 3 = C . (8.84)

8.3.6Integrating Factors

If the equation M ( x , y ) d x + N ( x , y ) d y = 0 is not exact, it may sometimes be made exact by multiplying by a function μ ( x , y ) called an integrating factor:

μ ( x , y ) M ( x , y ) d x + μ ( x , y ) N ( x , y ) d y = 0. (8.85)

The new equation is exact if

∂ ( μ M ) ∂ y = ∂ ( μ N ) ∂ x . (8.86)

Unfortunately, there is no universal method for finding μ ( x , y ) . However, there are two common and important special cases.

Case 1: Integrating factor depends on x only.

If μ = μ ( x ) , then the equation becomes exact provided that

1 μ d μ d x = ∂ M ∂ y − ∂ N ∂ x N . (8.87)

Hence,

μ ( x ) = exp ( ∫ 1 N ( ∂ M ∂ y − ∂ N ∂ x ) d x ) . (8.88)

Case 2: Integrating factor depends on y only.

If μ = μ ( y ) , then the equation becomes exact provided that

1 μ d μ d y = ∂ N ∂ x − ∂ M ∂ y M . (8.89)

Hence,

μ ( y ) = exp ( ∫ 1 M ( ∂ N ∂ x − ∂ M ∂ y ) d y ) . (8.90)
Example - Integrating factor μ = μ ( x ) , not separable

Solve

[ ( x + 1 ) y + x ] d x + x d y = 0. (8.91)

Solution.

Step 1. Identify M , N and test exactness.

M ( x , y ) = ( x + 1 ) y + x , N ( x , y ) = x . (8.92)

Compute

M y = x + 1 , N x = 1. (8.93)

Since M y ≠ N x , the equation is not exact.

Step 2. Seek an integrating factor μ = μ ( x ) . Use

1 μ d μ d x = M y − N x N = ( x + 1 ) − 1 x = x x = 1. (8.94)

Hence

ln ⁡ μ ( x ) = ∫ 1 d x = x ⇒ μ ( x ) = e x . (8.95)

Step 3. Multiply the equation by μ ( x ) = e x .

e x [ ( x + 1 ) y + x ] d x + e x x d y = 0. (8.96)

Define

M ~ = e x [ ( x + 1 ) y + x ] , N ~ = e x x . (8.97)

Step 4. Check exactness \& find a potential U ( x , y ) .

∂ M ~ ∂ y = e x ( x + 1 ) , ∂ N ~ ∂ x = e x ( x + 1 ) ⇒ exact . (8.98)

Integrate M ~ w.r.t. x (treating y constant):

U ( x , y ) = ∫ e x [ ( x + 1 ) y + x ] d x = y ∫ e x ( x + 1 ) d x + ∫ x e x d x . (8.99)

Using ∫ e x ( x + 1 ) d x = x e x and ∫ x e x d x = ( x − 1 ) e x ,

U ( x , y ) = y x e x + ( x − 1 ) e x + F ( y ) . (8.100)

Now

U y = x e x + F ′ ( y ) = ! N ~ = x e x ⇒ F ′ ( y ) = 0 ⇒ F ( y ) = const . (8.101)

Step 5. Implicit solution.

e x ( x y + x − 1 ) = C . (8.102)
Example - Integrating factor μ = μ ( y ) , not separable

Solve

y d x + ( 3 x + y ) d y = 0. (8.103)

Solution.

Step 1. Identify M , N and test exactness.

M ( x , y ) = y , N ( x , y ) = 3 x + y . (8.104)

Compute

M y = 1 , N x = 3. (8.105)

Since M y ≠ N x , the equation is not exact.

Step 2. Seek an integrating factor μ = μ ( y ) . Use

1 μ d μ d y = N x − M y M = 3 − 1 y = 2 y . (8.106)

Hence

ln ⁡ μ ( y ) = ∫ 2 y d y = 2 ln ⁡ | y | ⇒ μ ( y ) = y 2 ( y ≠ 0 ) . (8.107)

Step 3. Multiply the equation by μ ( y ) = y 2 .

y 3 d x + ( 3 x y 2 + y 3 ) d y = 0. (8.108)

Define

M ~ = y 3 , N ~ = 3 x y 2 + y 3 . (8.109)

Step 4. Check exactness \& find a potential U ( x , y ) .

∂ M ~ ∂ y = 3 y 2 , ∂ N ~ ∂ x = 3 y 2 ⇒ exact . (8.110)

Integrate M ~ w.r.t. x (treating y constant):

U ( x , y ) = ∫ y 3 d x = x y 3 + F ( y ) . (8.111)

Now

U y = 3 x y 2 + F ′ ( y ) = ! N ~ = 3 x y 2 + y 3 ⇒ F ′ ( y ) = y 3 ⇒ F ( y ) = y 4 4 . (8.112)

Step 5. Implicit solution.

x y 3 + y 4 4 = C . (8.113)
Remark

Many physical systems—such as thermodynamics, potential flow, and electrostatics—lead to exact differential equations, where U ( x , y ) represents a potential energy, enthalpy, or potential function. When the equation is not exact, an integrating factor often restores this structure.

8.4Second-Order Ordinary Differential Equations

A second-order linear ordinary differential equation (ODE) has the general form

a 2 ( x ) y ″ + a 1 ( x ) y ′ + a 0 ( x ) y = f ( x ) , (8.114)

where a 2 ( x ) , a 1 ( x ) , a 0 ( x ) , and f ( x ) are known functions of x , and y ( x ) is the unknown function to be determined.

When a 2 , a 1 , a 0 are constants, the equation simplifies to

a y ″ + b y ′ + c y = f ( x ) , a , b , c ∈ R ,   a ≠ 0. (8.115)

We will first study the homogeneous case ( f ( x ) = 0 ) and then the nonhomogeneous case ( f ( x ) ≠ 0 ).

8.4.1Homogeneous Equations with Constant Coefficients

Definition - Homogeneous Linear ODE (Second Order)

A second–order homogeneous linear differential equation with constant coefficients has the form

a y ″ + b y ′ + c y = 0 , a , b , c ∈ R ,   a ≠ 0. (8.116)
Theorem - General Solution of a Constant–Coefficient ODE

Consider the homogeneous linear differential equation

a y ″ + b y ′ + c y = 0 , a ≠ 0. (8.117)

Its solutions are determined by the characteristic (auxiliary) equation

a r 2 + b r + c = 0. (8.118)

If r 1 and r 2 are the roots of this quadratic, then the general solution is:

(i) Distinct real roots  r 1 ≠ r 2 : y ( x ) = C 1 e r 1 x + C 2 e r 2 x , (ii) Repeated root  r 1 = r 2 = r : y ( x ) = ( C 1 + C 2 x ) e r x , (iii) Complex roots  r = α ± i β : y ( x ) = e α x ( C 1 cos ⁡ ( β x ) + C 2 sin ⁡ ( β x ) ) , (8.119)

where C 1 , C 2 are arbitrary constants.

Consider the homogeneous constant–coefficient ODE

a y ″ + b y ′ + c y = 0 , a ≠ 0. (8.120)

Step 1: Exponential trial and substitution. Assume a trial solution y = e r x with constant r . Then

y ′ = r e r x , y ″ = r 2 e r x . (8.121)

Substituting into the ODE gives

a ( r 2 e r x ) + b ( r e r x ) + c ( e r x ) = e r x ( a r 2 + b r + c ) = 0. (8.122)

Since e r x ≠ 0 for all x , we must have the characteristic equation

a r 2 + b r + c = 0. (8.123)

Step 2: Distinct real roots r 1 ≠ r 2 . If the characteristic polynomial has two distinct real roots r 1 and r 2 , then

y 1 = e r 1 x , y 2 = e r 2 x (8.124)

are both solutions. Their Wronskian is

W [ y 1 , y 2 ] ( x ) = | e r 1 x e r 2 x r 1 e r 1 x r 2 e r 2 x | = ( r 2 − r 1 ) e ( r 1 + r 2 ) x ≠ 0 , (8.125)

so y 1 , y 2 are linearly independent. Hence the general solution is

y ( x ) = C 1 e r 1 x + C 2 e r 2 x . (8.126)

Step 3: Repeated real root r 1 = r 2 = r . (Construction of the x e r x term.) If the characteristic polynomial has a double root r , then we already have one solution y 1 = e r x . To find a second, linearly independent solution, set

y 2 ( x ) = v ( x ) e r x , (8.127)

where v is to be determined. Compute derivatives:

y 2 ′ = v ′ e r x + r v e r x , y 2 ″ = v ″ e r x + 2 r v ′ e r x + r 2 v e r x . (8.128)

Substitute y 2 , y 2 ′ , y 2 ″ into the ODE:

a ( v ″ + 2 r v ′ + r 2 v ) e r x + b ( v ′ + r v ) e r x + c ( v ) e r x = 0. (8.129)

Divide by e r x ≠ 0 and group terms by v ″ , v ′ , v :

a v ″ + ( 2 a r + b ) v ′ + ( a r 2 + b r + c ) v = 0. (8.130)

Because r is a root of the characteristic polynomial, we have

a r 2 + b r + c = 0. (8.131)

Moreover, because the root is repeated, the derivative of the characteristic polynomial also vanishes at r :

d d r ( a r 2 + b r + c ) | r = 2 a r + b = 0. (8.132)

Hence the equation for v reduces to

a v ″ = 0 ⇒ v ″ = 0 ⇒ v ( x ) = A x + B . (8.133)

Discarding the multiple of the first solution (the B e r x part), we take v ( x ) = x and obtain

y 2 ( x ) = x e r x . (8.134)

Therefore, the general solution in the repeated-root case is

y ( x ) = ( C 1 + C 2 x ) e r x . (8.135)

Step 4: Complex conjugate roots r = α ± i β with β ≠ 0 . If r = α ± i β , then e ( α ± i β ) x are solutions. Taking real and imaginary parts,

e α x cos ⁡ ( β x ) , e α x sin ⁡ ( β x ) (8.136)

are real solutions. Their Wronskian is

W [ e α x cos ⁡ β x , e α x sin ⁡ β x ] = β e 2 α x ≠ 0 , (8.137)

so they are linearly independent. Thus the general real solution is

y ( x ) = e α x ( C 1 cos ⁡ β x + C 2 sin ⁡ β x ) . (8.138)

Combining the three cases completes the proof.

Remark

  • The step 2 a r + b = 0 in the repeated-root case is precisely the condition p ′ ( r ) = 0 where p ( r ) = a r 2 + b r + c . This is why the reduction–of–order equation collapses to v ″ = 0 , giving v ( x ) = x and hence y 2 = x e r x .

  • The Wronskians shown above explicitly verify linear independence in the distinct-root and complex-root cases.

  • The exponential ansatz works here because constant coefficients make the ODE invariant under differentiation of e r x : derivatives only pull down factors of r , converting the differential equation to an algebraic one.

8.4.2Nonhomogeneous Equations

Definition

A nonhomogeneous second-order linear ODE is

a y ″ + b y ′ + c y = f ( x ) , (8.139)

where f ( x ) is a known forcing (nonzero) function.

Theorem

The general solution of a nonhomogeneous linear ODE is

y ( x ) = y h ( x ) + y p ( x ) , (8.140)

where

  • y h ( x ) is the homogeneous (complementary) solution satisfying a y ″ + b y ′ + c y = 0 ,

  • y p ( x ) is a particular solution satisfying the full equation for the given f ( x ) .

Definition - Method of Undetermined Coefficients

If f ( x ) is composed of elementary functions such as exponentials, polynomials, or sines and cosines, we assume a trial form for y p ( x ) resembling f ( x ) , substitute into the ODE, and solve for the unknown coefficients.

If any term of the assumed y p ( x ) duplicates a part of y h ( x ) , multiply by the smallest power of x necessary to ensure linear independence.

8.4.3Example: Forced and Damped Harmonic Oscillator

Example - Forced and Damped Harmonic Oscillator (dot notation)

Consider the driven, damped oscillator

m x ¨ + b x ˙ + k x = F 0 sin ⁡ ( ω t ) , (8.141)

where m is the mass, b the damping coefficient, k the spring constant, and F 0 sin ⁡ ( ω t ) the external driving force.

Solution.

Divide through by m :

x ¨ + 2 γ x ˙ + ω 0 2 x = F 0 m sin ⁡ ( ω t ) , (8.142)

where

ω 0 = k m , 2 γ = b m . (8.143)

Step 2. Homogeneous solution.

For the unforced system,

x ¨ h + 2 γ x ˙ h + ω 0 2 x h = 0 , (8.144)

the characteristic equation is

r 2 + 2 γ r + ω 0 2 = 0 , r = − γ ± i ω d , (8.145)

where

ω d = ω 0 2 − γ 2 (8.146)

is the damped natural frequency. Hence,

x h ( t ) = e − γ t ( C 1 cos ⁡ ω d t + C 2 sin ⁡ ω d t ) . (8.147)

Step 3. Particular (steady–state) solution using complex amplitude.

We look for a steady–state oscillation at the same frequency as the driving force. To simplify the algebra, we use a complex trial solution.

Step 3(a). Choose a complex trial solution.

Assume

x p ( t ) = Im { z 0 e i ω t } , (8.148)

where z 0 is a complex constant. We may write

z 0 = A e i ϕ , (8.149)

so that

x p ( t ) = Im { A e i ( ω t + ϕ ) } = A sin ⁡ ( ω t + ϕ ) . (8.150)

Step 3(b). Substitute into the differential equation.

The driven damped oscillator equation (after dividing by m ) is

d 2 x d t 2 + 2 γ d x d t + ω 0 2 x = F 0 m sin ⁡ ( ω t ) = Im { F 0 m e i ω t } . (8.151)

We substitute the full complex function z 0 e i ω t :

d d t ( z 0 e i ω t ) = i ω z 0 e i ω t , d 2 d t 2 ( z 0 e i ω t ) = − ω 2 z 0 e i ω t . (8.152)

Substituting into the ODE gives

( − ω 2 z 0 + 2 γ i ω z 0 + ω 0 2 z 0 ) e i ω t = F 0 m e i ω t . (8.153)

Step 3(c). Cancel e i ω t .

( − ω 2 + i 2 γ ω + ω 0 2 ) z 0 = F 0 m . (8.154)

Step 3(d). Solve for the complex amplitude z 0 .

z 0 = F 0 / m ω 0 2 − ω 2 + i 2 γ ω . (8.155)

Write the denominator in polar form:

ω 0 2 − ω 2 + i 2 γ ω = R e i ϕ , (8.156)

where

R = ( ω 0 2 − ω 2 ) 2 + ( 2 γ ω ) 2 , tan ⁡ ϕ = 2 γ ω ω 0 2 − ω 2 . (8.157)

Thus,

z 0 = F 0 / m R e − i ϕ . (8.158)

Step 3(e). Take the imaginary part.

x p ( t ) = Im { z 0 e i ω t } = F 0 / m R Im { e i ( ω t − ϕ ) } = F 0 / m R sin ⁡ ( ω t − ϕ ) . (8.159)

Final steady–state response:

x p ( t ) = F 0 / m ( ω 0 2 − ω 2 ) 2 + ( 2 γ ω ) 2 sin ⁡ ( ω t − ϕ ) (8.160)

with

tan ⁡ ϕ = 2 γ ω ω 0 2 − ω 2 . (8.161)

Step 4. Complete solution.

x ( t ) = e − γ t ( C 1 cos ⁡ ω d t + C 2 sin ⁡ ω d t ) + F 0 / m ( ω 0 2 − ω 2 ) 2 + ( 2 γ ω ) 2 sin ⁡ ( ω t − ϕ ) . (8.162)

Step 5. Physical interpretation.

  • x h ( t ) : Transient response, which decays exponentially as e − γ t and oscillates with the damped frequency ω d .

  • x p ( t ) : Steady–state response, which oscillates at the driving frequency ω .

  • For weak damping ( γ ≪ ω 0 ), the steady–state amplitude is

    A ( ω ) = F 0 / m ( ω 0 2 − ω 2 ) 2 + ( 2 γ ω ) 2 . (8.163)

  • The amplitude reaches a maximum (resonance) when the driving frequency is close to the natural frequency of oscillation,

    ω ≈ ω 0 . (8.164)

    More precisely, minimising the denominator ( ω 0 2 − ω 2 ) 2 + ( 2 γ ω ) 2 gives the peak at ω res = ω 0 2 − 2 γ 2 , which reduces to ω 0 in the weak-damping limit γ ≪ ω 0 . Evaluating the amplitude at ω = ω 0 ,

    A ( ω 0 ) = F 0 / m 2 γ ω 0 = F 0 2 m γ ω 0 , (8.165)

    which is large when γ is small — the amplitude at resonance is limited only by the damping, and would diverge if γ → 0 .

As t → ∞ , the transient term x h ( t ) vanishes and only the steady oscillation x p ( t ) remains.

8.5Where Differential Equations Are Used

A differential equation is a statement about how a quantity changes, and change is what physics is about. The forced damped oscillator worked at the end of this chapter is not one example among many — it is the template. The same equation m x ¨ + b x ˙ + k x = F ( t ) , with the symbols reinterpreted, governs a startling range of systems.

  • Mechanical vibration. Mass on a spring, a pendulum, a building swaying in wind: all are m x ¨ + b x ˙ + k x = F ( t ) , and the resonance condition ω ≈ ω 0 is why soldiers break step on bridges.

  • Electrical circuits. The series RLC circuit obeys L q ¨ + R q ˙ + q / C = V ( t ) , identical in form to the oscillator with L ↔ m , R ↔ b , 1 / C ↔ k . Resonance here is how a radio selects a station.

  • Growth and decay. The first-order equation y ˙ = k y describes radioactive decay, population growth, cooling, and the charging of a capacitor — the separable equations of this chapter.

  • Chemical kinetics and mixing. Reaction rates and concentration in a stirred tank are first-order linear ODEs solved by the integrating factor.

  • The starting point for everything later. Series solutions (Chapter 9) handle ODEs with variable coefficients that these elementary methods cannot; partial differential equations (Chapter 10) are solved by separating them into ordinary ones.

Remark

Two ideas from this chapter carry the most weight later. First, for a linear equation the general solution is y h + y p : the full space of solutions is a particular solution plus the entire solution set of the homogeneous equation. Second, the exponential ansatz y = e r x turns a constant-coefficient linear ODE into an algebraic equation, because differentiating e r x only multiplies it by r . Almost every linear system in physics is attacked by some version of these two moves.
