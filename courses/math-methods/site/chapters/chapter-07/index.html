7.1Even and Odd Functions

Video Lecture 20, Part 2: Even and Odd Functions (4:18)

DefinitionEven and Odd Functions

  • A function f ( x ) is said to be even if

    f ( − x ) = f ( x ) . (7.1)

  • A function f ( x ) is said to be odd if

    f ( − x ) = − f ( x ) . (7.2)

Properties of Integrals over Symmetric Limits:

If  f ( x )  is even: ∫ − L / 2 L / 2 f ( x ) d x = 2 ∫ 0 L / 2 f ( x ) d x , If  f ( x )  is odd: ∫ − L / 2 L / 2 f ( x ) d x = 0. (7.3)
Remark

In general, any function f ( x ) can be expressed as the sum of an even and an odd function:

f ( x ) = 1 2 [ f ( x ) + f ( − x ) ] + 1 2 [ f ( x ) − f ( − x ) ] . (7.4)

The first term is the even part of f ( x ) , and the second term is the odd part.

7.2Periodic Functions and Fourier Series

Video Lecture 20, Part 3: Periodic Functions and the Waves That Fit (8:40)

DefinitionPeriodic Function

A function f ( x ) is said to be periodic with period L > 0 if

f ( x + L ) = f ( x ) for all  x . (7.5)

The smallest positive L satisfying this relation is called the fundamental period.

Remark

Common periodic functions include

sin ( 2 π x L ) , cos ( 2 π x L ) , e i 2 π x L , (7.6)

all sharing the same fundamental period L .

DefinitionAverage Value of a Function

For a periodic function f ( x ) of period L , the average value (or mean value) of the function over one period is defined as

⟨ f ⟩ = 1 L ∫ − L / 2 L / 2 f ( x ) d x . (7.7)

7.2.1Fundamental Periodic Basis

For the exponential function e i k x to have period L ,

e i k ( x + L ) = e i k x ⇒ e i k L = 1. (7.8)

Since e i 2 π n = 1 for integers n , we have

k n = 2 π n L , n = 0 , ± 1 , ± 2 , … (7.9)

Thus, the functions

e i k n x = e i 2 π n x L (7.10)

form a complete orthogonal set over one period.

RemarkOrthogonality
∫ − L / 2 L / 2 e i k m x e − i k n x d x = L δ m n . (7.11)

For n ≠ m the product e i ( k m − k n ) x turns a whole number of times in one period, so its real and imaginary parts have as much area above the axis as below; for n = m it is 1 , with area L .

7.2.2Complex Fourier Series

Video Lecture 20, Part 4: The Complex Fourier Series (12:39)

DefinitionComplex Fourier Series

A periodic function f ( x ) of period L can be represented as

f ( x ) = ∑ n = − ∞ ∞ c n e i k n x , k n = 2 π n L , (7.12)

where the coefficients are

c n = 1 L ∫ − L / 2 L / 2 f ( x ) e − i k n x d x . (7.13)

The list of all the coefficients c n is the shape's recipe (as the lecture videos call it), or its spectrum: how much of each pure wave goes in.

Starting from f ( x ) = ∑ c n e i k n x , multiply by e − i k m x and integrate:

∫ − L / 2 L / 2 f ( x ) e − i k m x d x = ∑ n c n ∫ − L / 2 L / 2 e i ( k n − k m ) x d x = L c m , (7.14)

by orthogonality. Hence,

c m = 1 L ∫ − L / 2 L / 2 f ( x ) e − i k m x d x . (7.15)
Remark

For a real-valued function f ( x ) , the complex coefficients satisfy

c − n = c n ∗ . (7.16)

7.2.3Real Form of the Fourier Series

Video Lecture 20, Part 5: The Real Form and Its Coefficients (19:05)

TheoremReal Form of the Fourier Series
f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ( 2 π n x L ) + b n sin ( 2 π n x L ) ] . (7.17)

Starting from the complex Fourier series.

We begin with the complex form of the Fourier series for a periodic function f ( x ) of period L :

f ( x ) = ∑ n = − ∞ ∞ c n e i k n x , where  k n = 2 π n L . (7.18)

We separate the n = 0 term and rearrange positive and negative indices:

f ( x ) = c 0 + ∑ n = 1 ∞ ( c n e i k n x + c − n e − i k n x ) . (7.19)

Using c − n = c n ∗ , we have

f ( x ) = c 0 + ∑ n = 1 ∞ ( c n e i k n x + c n ∗ e − i k n x ) . (7.20)

Expressing in terms of sine and cosine.

Let

c 0 = a 0 2 c n = 1 2 ( a n − i b n ) , c n ∗ = 1 2 ( a n + i b n ) , (7.21)

where a n and b n are real numbers.

Then

c n e i k n x + c n ∗ e − i k n x = 1 2 [ ( a n − i b n ) ( cos ⁡ k n x + i sin ⁡ k n x ) + ( a n + i b n ) ( cos ⁡ k n x − i sin ⁡ k n x ) ] = a n cos ⁡ k n x + b n sin ⁡ k n x . (7.22)

Hence the series becomes

f ( x ) = a 0 2 + ∑ n = 1 ∞ ( a n cos ⁡ k n x + b n sin ⁡ k n x ) . (7.23)

Thus the final real form of the Fourier series is

f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ⁡ ( 2 π n x L ) + b n sin ⁡ ( 2 π n x L ) ] . (7.24)
Remark

  • a 0 2 : average (DC component) of f ( x ) ,

  • a n : amplitude of the cosine component,

  • b n : amplitude of the sine component,

  • frequency of the n -th harmonic: f n = n L .

TheoremFourier Coefficients

For f ( x ) of period L :

a 0 = 2 L ∫ − L / 2 L / 2 f ( x ) d x , a n = 2 L ∫ − L / 2 L / 2 f ( x ) cos ( 2 π n x L ) d x , b n = 2 L ∫ − L / 2 L / 2 f ( x ) sin ( 2 π n x L ) d x . (7.25)

Multiply both sides of the Fourier expansion by cos ( 2 π m x L ) and integrate over one period:

∫ − L / 2 L / 2 f ( x ) cos ( 2 π m x L ) d x = ∫ − L / 2 L / 2 [ a 0 + ∑ n = 1 ∞ ( a n cos 2 π n x L + b n sin 2 π n x L ) ] cos ( 2 π m x L ) d x . (7.26)

Using the orthogonality relations:

∫ − L / 2 L / 2 cos ( 2 π m x L ) d x = 0 , ∫ − L / 2 L / 2 cos ( 2 π n x L ) cos ( 2 π m x L ) d x = L 2 δ m n , ∫ − L / 2 L / 2 sin ( 2 π n x L ) cos ( 2 π m x L ) d x = 0 , (7.27)

all terms vanish except the one where n = m :

∫ − L / 2 L / 2 f ( x ) cos ( 2 π m x L ) d x = a m L 2 . (7.28)

Hence,

a m = 2 L ∫ − L / 2 L / 2 f ( x ) cos ( 2 π m x L ) d x . (7.29)

Similarly, multiplying the Fourier series by sin ( 2 π m x L ) and integrating gives

b m = 2 L ∫ − L / 2 L / 2 f ( x ) sin ( 2 π m x L ) d x . (7.30)

Finally, integrating both sides of the Fourier expansion over one period. Since the integrals of all sine and cosine terms vanish over a full period, only the constant term a 0 2 survives:

∫ − L / 2 L / 2 f ( x ) d x = ∫ − L / 2 L / 2 a 0 2 d x = a 0 2 L . (7.31)

Hence,

a 0 = 2 L ∫ − L / 2 L / 2 f ( x ) d x , (7.32)

consistent with the general formula for a n at n = 0 . Note that it is a 0 2 , not a 0 , that equals the average value (mean) of f ( x ) over one period; writing the constant term as a 0 2 is precisely what lets the single formula a n = 2 L ∫ f cos ⁡ ( 2 π n x / L ) d x cover the case n = 0 .

7.2.4Dirichlet Conditions and Convergence of Fourier Series

Video Lecture 20, Part 6: When It Works: Dirichlet (23:40)

DefinitionDirichlet Conditions

A periodic function f ( x ) of period L can be represented by a Fourier series (without modification) on the interval [ − L 2 , L 2 ] if it satisfies the following conditions:

  1. f ( x ) is single-valued and piecewise continuous within one period.

  2. f ( x ) has a finite number of finite discontinuities.

  3. f ( x ) has a finite number of maxima and minima within one period.

  4. The integral of its absolute value over one period is finite:

    ∫ − L / 2 L / 2 | f ( x ) | d x < ∞ . (7.33)
TheoremConvergence of the Fourier Series

If f ( x ) satisfies the Dirichlet conditions and has period L , then its Fourier series

f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ( 2 π n x L ) + b n sin ( 2 π n x L ) ] (7.34)

converges as follows:

  • At every point where f ( x ) is continuous, the Fourier series converges to f ( x ) .

  • At each point of discontinuity x 0 , the Fourier series converges to the midpoint of the jump:

    f series ( x 0 ) = 1 2 [ f ( x 0 + ) + f ( x 0 − ) ] . (7.35)

7.2.5Meaning and Interpretation of the Fourier Series

Video Lecture 20, Part 7: What the Harmonics Mean (26:03)

The Fourier series allows us to express any sufficiently smooth periodic function f ( x ) (with period L ) as a sum of simple oscillatory components — sine and cosine waves. Mathematically,

f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ⁡ ( k n x ) + b n sin ⁡ ( k n x ) ] , k n = 2 π n L . (7.36)

Each term in the sum represents a harmonic component (or mode) of the signal.

DefinitionHarmonic Component

The n -th term in the Fourier series,

ϕ n ( x ) = a n cos ⁡ ( k n x ) + b n sin ⁡ ( k n x ) , (7.37)

is called the n -th harmonic. It corresponds to a wave of frequency

ν n = n L or angular frequency ω n = k n = 2 π n L . (7.38)

Thus,

ϕ 0 ( x ) = a 0 2 , (average or DC component) ϕ 1 ( x ) = a 1 cos ⁡ ( k 1 x ) + b 1 sin ⁡ ( k 1 x ) , (fundamental harmonic) ϕ 2 ( x ) = a 2 cos ⁡ ( 2 k 1 x ) + b 2 sin ⁡ ( 2 k 1 x ) , (second harmonic) ϕ N ( x ) = a N cos ⁡ ( N k 1 x ) + b N sin ⁡ ( N k 1 x ) , ( N -th harmonic) . (7.39)

Each harmonic contributes a specific frequency, amplitude, and phase to the total waveform. The original function f ( x ) is reconstructed by summing all harmonic components:

f ( x ) = ϕ 0 ( x ) + ϕ 1 ( x ) + ϕ 2 ( x ) + ⋯ = ∑ n = 0 ∞ ϕ n ( x ) . (7.40)

As more harmonics are included, the approximation of f ( x ) becomes more accurate. Lower harmonics ( n = 0 , 1 , 2 ) describe the overall shape, while higher harmonics capture finer details and sharp transitions.

Applications in Signal Processing

DefinitionLow-Pass Filter

A low-pass filter removes high-frequency (large n ) components from a signal, keeping only low-frequency terms:

f filtered ( x ) = ∑ n = 0 N ϕ n ( x ) , (7.41)

where N sets the cutoff frequency.

RemarkApplications

  • Signal processing: Decompose and reconstruct signals by frequency content.

  • Noise reduction: Remove unwanted high-frequency components using low-pass filtering.

  • Data compression: Approximate a signal using only the dominant harmonics.

  • Physics: Analyze normal modes in vibrating strings, membranes, and quantum systems.

ExampleSquare step on [ − π , π ]

Find the Fourier series of

f ( x ) = { 0 , − π < x < 0 , 1 , 0 < x < π , (period  2 π ) . (7.42)

Fourier form on [ − π , π ] . With period L = 2 π , the series is

f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ⁡ ( n x ) + b n sin ⁡ ( n x ) ] , (7.43)

where, from the coefficient formulas with L = 2 π so that 2 L = 1 π ,

a 0 = 1 π ∫ − π π f ( x ) d x , a n = 1 π ∫ − π π f ( x ) cos ⁡ ( n x ) d x , b n = 1 π ∫ − π π f ( x ) sin ⁡ ( n x ) d x . (7.44)

Solution.

Step 1: a 0 . The constant term of the series is a 0 2 , so we expect it to equal the average of f , namely 1 2 .

a 0 = 1 π ∫ − π π f ( x ) d x = 1 π ∫ 0 π 1 d x = 1 ⇒ a 0 2 = 1 2 . (7.45)

Step 2: a n (all n ≥ 1 ).

a n = 1 π ∫ 0 π cos ⁡ ( n x ) d x = 1 π ⋅ sin ⁡ ( n x ) n | 0 π = 0. (7.46)

Step 3: b n (all n ≥ 1 ).

b n = 1 π ∫ 0 π sin ⁡ ( n x ) d x = 1 π ⋅ − cos ⁡ ( n x ) n | 0 π = 1 n π ( 1 − cos ⁡ ( n π ) ) = 1 − ( − 1 ) n n π . (7.47)

Hence

b n = { 0 , n   even , 2 n π , n   odd . (7.48)

Result.

f ( x ) = 1 2 + 2 π ( sin ⁡ x + sin ⁡ 3 x 3 + sin ⁡ 5 x 5 + ⋯ ) (7.49)

(i.e., the sum runs over odd n ). At the jump points x ≡ 0 , π   ( mod   2 π ) , the series converges to the average 1 2 (Dirichlet’s theorem).

ExamplePeriodic ramp on ( 0 , π ) (period 2 π )

Fourier form on [ − π , π ] (period 2 π ).

f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ⁡ ( n x ) + b n sin ⁡ ( n x ) ] , a 0 = 1 π ∫ − π π f ( x ) d x , a n = 1 π ∫ − π π f ( x ) cos ⁡ ( n x ) d x , b n = 1 π ∫ − π π f ( x ) sin ⁡ ( n x ) d x . (7.50)

Solution.

a 0 = 1 π ∫ 0 π x d x = 1 π [ x 2 2 ] 0 π = π 2 ⇒ a 0 2 = π 4 . (7.51)

Step 2: Cosine coefficients ( n ≥ 1 ).

a n = 1 π ∫ 0 π x cos ⁡ ( n x ) d x ( IBP:  u = x ,   d v = cos ⁡ n x d x ⇒ v = 1 n sin ⁡ n x ) . (7.52)
a n = 1 π [ x sin ⁡ ( n x ) n ] 0 π − 1 π ∫ 0 π sin ⁡ ( n x ) n d x = 1 π n 2 ( cos ⁡ n π − 1 ) = ( − 1 ) n − 1 π n 2 = { 0 , n   even , − 2 π n 2 , n   odd . (7.53)

Step 3: Sine coefficients ( n ≥ 1 ).

b n = 1 π ∫ 0 π x sin ⁡ ( n x ) d x ( IBP:  u = x ,   d v = sin ⁡ n x d x ⇒ v = − 1 n cos ⁡ n x ) . (7.54)
b n = 1 π [ − x cos ⁡ ( n x ) n ] 0 π + 1 π ∫ 0 π cos ⁡ ( n x ) n d x = − ( − 1 ) n n = ( − 1 ) n + 1 n . (7.55)

Final series.

f ( x ) = π 4 + ∑ n = 1 ∞ [ ( − 1 ) n − 1 π n 2 cos ⁡ ( n x ) + ( − 1 ) n + 1 n sin ⁡ ( n x ) ] (7.56)

or, separating even/odd indices,

f ( x ) = π 4 − 2 π ∑ k = 0 ∞ cos ⁡ ( ( 2 k + 1 ) x ) ( 2 k + 1 ) 2 + ∑ n = 1 ∞ ( − 1 ) n + 1 n sin ⁡ ( n x ) . (7.57)

At the jump points x ≡ 0 , π   ( mod   2 π ) , the series converges to the midpoint value 1 2 ( 0 + π ) = π 2 .

ExamplePeriodic half-ramp

Let

f ( t ) = { 0 , − T 2 < t < 0 , t , 0 < t < T 2 , extended periodically with period  T . (7.58)

We find its real Fourier series

f ( t ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ⁡ ( ω n t ) + b n sin ⁡ ( ω n t ) ] , ω n = 2 π n T . (7.59)

Solution.

a 0 = 2 T ∫ − T / 2 T / 2 f ( t ) d t = 2 T ∫ 0 T / 2 t d t = 2 T ⋅ ( T / 2 ) 2 2 = T 4 . (7.60)

Hence the DC term is a 0 / 2 = T / 8 .

Step 2: Cosine coefficients.

a n = 2 T ∫ − T / 2 T / 2 f ( t ) cos ⁡ ( ω n t ) d t = 2 T ∫ 0 T / 2 t cos ⁡ ( ω n t ) d t . (7.61)

Integration by parts with u = t , d v = cos ⁡ ( ω n t ) d t gives

∫ t cos ⁡ ( ω n t ) d t = t sin ⁡ ( ω n t ) ω n + cos ⁡ ( ω n t ) ω n 2 . (7.62)

Therefore

a n = 2 T [ t sin ⁡ ( ω n t ) ω n + cos ⁡ ( ω n t ) ω n 2 ] 0 T / 2 = 2 T [ ( T / 2 ) sin ⁡ ( ω n T / 2 ) ω n + cos ⁡ ( ω n T / 2 ) − 1 ω n 2 ] . (7.63)

Using sin ⁡ ( ω n T / 2 ) = sin ⁡ ( n π ) = 0 and cos ⁡ ( ω n T / 2 ) = cos ⁡ ( n π ) = ( − 1 ) n ,

a n = 2 T ⋅ ( − 1 ) n − 1 ω n 2 = T 2 π 2 n 2 [ ( − 1 ) n − 1 ] . (7.64)

Hence

a n = 0   for even  n , a n = − T π 2 n 2   for odd  n . (7.65)

Step 3: Sine coefficients.

b n = 2 T ∫ − T / 2 T / 2 f ( t ) sin ⁡ ( ω n t ) d t = 2 T ∫ 0 T / 2 t sin ⁡ ( ω n t ) d t . (7.66)

With u = t , d v = sin ⁡ ( ω n t ) d t ,

∫ t sin ⁡ ( ω n t ) d t = − t cos ⁡ ( ω n t ) ω n + sin ⁡ ( ω n t ) ω n 2 . (7.67)

Thus

b n = 2 T [ − t cos ⁡ ( ω n t ) ω n + sin ⁡ ( ω n t ) ω n 2 ] 0 T / 2 = − 2 T ⋅ ( T / 2 ) cos ⁡ ( ω n T / 2 ) ω n = ( − 1 ) n + 1 ω n = ( − 1 ) n + 1 T 2 π n . (7.68)

Result (real Fourier series).

f ( t ) = T 8 + ∑ n = 1 odd  n ∞ ( − T π 2 n 2 ) cos ( 2 π n t T ) + ∑ n = 1 ∞ ( − 1 ) n + 1 T 2 π n sin ( 2 π n t T ) . (7.69)

  • a n vanish for even n ; cosine terms appear only for odd harmonics and decay as 1 / n 2 .

  • b n decay as 1 / n with alternating sign, reflecting the sharp corner at t = 0 (Gibbs effect upon truncation).

  • The average (DC) level over a period is T / 8 .

Video Lecture 20, Part 10: The Sawtooth Is the Violin (37:29)

ExampleComplex Fourier Series of a Periodic Ramp Function f ( x ) = x (period L )

Consider a spatially periodic function

f ( x ) = x , − L 2 < x < L 2 , (7.70)

which repeats every interval of length L . This represents a periodic ramp waveform, analogous to a sawtooth pattern in signal processing.

Solution.

For a periodic function f ( x ) of period L , the complex Fourier coefficients are

c n = 1 L ∫ − L / 2 L / 2 f ( x ) e − i k n x d x , where  k n = 2 π n L . (7.71)

Substitute f ( x ) = x :

c n = 1 L ∫ − L / 2 L / 2 x e − i k n x d x . (7.72)

Step 2. Integration by parts.

Let

u = x , d v = e − i k n x d x ⇒ d u = d x , v = e − i k n x − i k n = i k n e − i k n x . (7.73)

Then

c n = 1 L [ u v ] − L / 2 L / 2 − 1 L ∫ − L / 2 L / 2 v d u = i L k n [ x e − i k n x ] − L / 2 L / 2 − i L k n ∫ − L / 2 L / 2 e − i k n x d x . (7.74)

Step 3. Simplify the second term.

The exponential integral gives

∫ − L / 2 L / 2 e − i k n x d x = 2 sin ⁡ ( k n L / 2 ) k n = 2 sin ⁡ ( π n ) k n = 0 , (7.75)

since sin ⁡ ( π n ) = 0 for all integer n . Hence, only the boundary term contributes.

Step 4. Evaluate the boundary term.

c n = i L k n [ L 2 e − i k n L / 2 − ( − L 2 ) e i k n L / 2 ] = i 2 k n ( e − i π n + e i π n ) = i k n cos ⁡ ( π n ) . (7.76)

Using cos ⁡ ( π n ) = ( − 1 ) n , we have

c n = i k n ( − 1 ) n = i L 2 π n ( − 1 ) n , n ≠ 0. (7.77)

Step 5. DC (zero-frequency) coefficient.

c 0 = 1 L ∫ − L / 2 L / 2 x d x = 0 , (7.78)

since f ( x ) = x is an odd function and its average over one period is zero.

Step 6. Complete complex Fourier series.

f ( x ) = ∑ n = − ∞ n ≠ 0 ∞ i L 2 π n ( − 1 ) n e i k n x , k n = 2 π n L . (7.79)

Interpretation.

  • The amplitude of each harmonic decreases as 1 / n , meaning higher-frequency components contribute less to the total waveform.

  • Because f ( x ) is an odd function, the coefficients c n are purely imaginary ( c − n = c n ∗ ), corresponding to a sine-only spectrum.

  • Truncating the series to a few terms yields a smooth approximation of the ramp—analogous to applying a low-pass filter that removes sharp discontinuities.

7.3Fourier Transform

Video Lecture 21, Part 1: From Series to Transform (0:00)

The Fourier transform can be viewed as the limiting case of the complex Fourier series when the period L → ∞ . In this limit, the function f ( x ) becomes nonperiodic, and the discrete spectrum of wave numbers becomes continuous.

Transition from Discrete to Continuous Spectrum

Consider a periodic function f ( x ) with period L :

f ( x ) = ∑ n = − ∞ ∞ c n e i k n x , k n = 2 π n L . (7.80)

When L → ∞ , the spacing between successive wave numbers becomes infinitesimal:

Δ k = k n + 1 − k n = 2 π L ⇒ Δ k → 0. (7.81)

The discrete index n is replaced by a continuous variable k :

∑ n = − ∞ ∞ ⟶ L 2 π ∫ − ∞ ∞ d k . (7.82)
DefinitionFourier Coefficient in Continuous Limit

Let

g ( k ) = L 2 π c n with k = k n . (7.83)

Then g ( k ) becomes a continuous function that represents the spectral amplitude density of f ( x ) .

Substituting into the series and taking the limit L → ∞ :

f ( x ) = ∑ n = − ∞ ∞ c n e i k n x = L 2 π ∑ n = − ∞ ∞ g ( k n ) e i k n x Δ k → L → ∞ ∫ − ∞ ∞ g ( k ) e i k x d k . (7.84)
DefinitionFourier Transform (F.T.) and Inverse Transform
f ( x ) = ∫ − ∞ ∞ g ( k ) e i k x d k , (Inverse Fourier Transform) g ( k ) = 1 2 π ∫ − ∞ ∞ f ( x ) e − i k x d x , (Fourier Transform). (7.85)
Remark

  • f ( x ) : function in the spatial (time) domain.

  • g ( k ) : its representation in the frequency (wave number) domain.

  • The transform pair is symmetric up to the normalization factor 1 / 2 π .

DefinitionFourier Transform (F.T.) and Inverse Transform in the Time Domain
f ( t ) = 1 2 π ∫ − ∞ ∞ g ( ω ) e i ω t d ω , (Inverse Fourier Transform) g ( ω ) = ∫ − ∞ ∞ f ( t ) e − i ω t d t , (Fourier Transform). (7.86)

Video Lecture 21, Part 2: The Pulse and the Sinc (4:17)

ExampleRectangular pulse of width 2 a

Let

f ( x ) = { 1 , − a < x < a , 0 , otherwise , a > 0. (7.87)

This is a nonperiodic rectangular pulse centered at the origin with total width 2 a and unit height.

We use the transform pair

g ( k ) = 1 2 π ∫ − ∞ ∞ f ( x ) e − i k x d x , f ( x ) = ∫ − ∞ ∞ g ( k ) e i k x d k . (7.88)

Solution.

g ( k ) = 1 2 π ∫ − a a e − i k x d x . (7.89)

Step 2. Evaluate the integral.

∫ e − i k x d x = e − i k x − i k ⇒ ∫ − a a e − i k x d x = e − i k a − e i k a − i k = 2 sin ⁡ ( k a ) k . (7.90)

Step 3. Simplify and express the result.

g ( k ) = 1 2 π ⋅ 2 sin ⁡ ( k a ) k = 1 π sin ⁡ ( k a ) k = a π sinc ( a k ) , sinc ( u ) = sin ⁡ u u . (7.91)

At k = 0 , we take the limit g ( 0 ) = lim k → 0 a π sinc ( a k ) = a π .

Key features.

  • g ( k ) is real, even, and has zeros at k = ± n π / a for n = 1 , 2 , 3 , … .

  • The main lobe width Δ k ∼ 2 π / a — increasing a (wider pulse) narrows the spectrum.

  • The transform pair summarizes the width–bandwidth tradeoff: a narrow function in k -space corresponds to a wide function in x -space and vice versa.

Video Lecture 21, Part 3: The Fading Note (7:46)

ExampleFourier Transform of f ( t ) = e − a | t |

Let

f ( t ) = e − a | t | , a > 0. (7.92)

This function decays exponentially on both sides of t = 0 :

We use the Fourier transform convention:

f ( t ) = ∫ − ∞ ∞ g ( ω ) e i ω t d ω , g ( ω ) = 1 2 π ∫ − ∞ ∞ f ( t ) e − i ω t d t . (7.93)

Solution.

g ( ω ) = 1 2 π [ ∫ − ∞ 0 e a t e − i ω t d t + ∫ 0 ∞ e − a t e − i ω t d t ] . (7.94)

Step 2. Evaluate each integral.

∫ 0 ∞ e − a t e − i ω t d t = 1 a + i ω , ∫ − ∞ 0 e a t e − i ω t d t = 1 a − i ω . (7.95)

Step 3. Combine the results:

g ( ω ) = 1 2 π ( 1 a + i ω + 1 a − i ω ) = 1 π a a 2 + ω 2 . (7.96)

Thus, the Fourier transform of e − a | t | is

g ( ω ) = 1 π a a 2 + ω 2 (7.97)

which is known as the Lorentzian function.

Shape of g ( ω ) :

As a increases, g ( ω ) becomes broader and shorter; as a decreases, it becomes narrower and taller.

7.4A Quantum Particle in Fourier Space

Video Lecture 21, Part 4: A Quantum Particle in Fourier Space (11:35)

The most important use of the transform in physics is in quantum mechanics. This section works one example on a line in full, assuming nothing beyond this chapter.

Wave function and momentum

In quantum mechanics a particle is described by its wave function ψ ( x ) . Its meaning (Born's rule): | ψ ( x ) | 2 d x is the probability of finding the particle between x and x + d x , so

P ( a ≤ x ≤ b ) = ∫ a b | ψ ( x ) | 2 d x , ∫ − ∞ ∞ | ψ ( x ) | 2 d x = 1 . (7.98)

Momentum enters through de Broglie's relation (1924), confirmed by electron diffraction: the pure wave e i k x is a particle with exactly one momentum,

p = ℏ k , ℏ = h 2 π = 1.055 × 10 − 34   J s . (7.99)

Since | e i k x | 2 = 1 everywhere, a pure wave has an exact momentum and no position at all. A particle held near one place is a sum of many pure waves, ψ ( x ) = ∫ g ( k ) e i k x d k , so its transform g ( k ) is its momentum recipe: how much of momentum ℏ k it carries.

The Gaussian particle

A particle held near the origin is described by the Gaussian wave function ψ ( x ) = A e − x 2 / 4 σ 2 . Squaring doubles the exponent, | ψ | 2 = A 2 e − x 2 / 2 σ 2 : the bell curve of statistics, of width (standard deviation) σ . To fix A we need the area under a bell.

ExampleThe Gaussian integral

Find I = ∫ − ∞ ∞ e − x 2 d x .

No antiderivative helps, so square it, writing the second copy with y :

I 2 = ∫ − ∞ ∞ e − x 2 d x ∫ − ∞ ∞ e − y 2 d y = ∬ e − ( x 2 + y 2 ) d x d y . (7.100)

The integrand is a round hill, so use polar coordinates (Chapter 5): x 2 + y 2 = r 2 , d x d y = r d r d θ . With u = r 2 ,

I 2 = ∫ 0 2 π d θ ∫ 0 ∞ e − r 2 r d r = 2 π ⋅ 1 2 ∫ 0 ∞ e − u d u = π . (7.101)

Hence

∫ − ∞ ∞ e − x 2 d x = π , ∫ − ∞ ∞ e − x 2 / 2 σ 2 d x = σ 2 π ( x = 2 σ u ) . (7.102)

So A 2 σ 2 π = 1 , and ψ ( x ) = ( 2 π σ 2 ) − 1 / 4 e − x 2 / 4 σ 2 .

ExampleThe transform of a Gaussian

Find the momentum recipe g ( k ) of the Gaussian particle.

By definition,

g ( k ) = A 2 π ∫ − ∞ ∞ e − x 2 / 4 σ 2 e − i k x d x , e − i k x = cos ⁡ ( k x ) − i sin ⁡ ( k x ) . (7.103)

The bell is even and sin ⁡ ( k x ) is odd, so the sine part integrates to zero, and g ( k ) = A 2 π G ( k ) with G ( k ) = ∫ − ∞ ∞ e − x 2 / 4 σ 2 cos ⁡ ( k x ) d x . Differentiate under the integral and use x e − x 2 / 4 σ 2 = − 2 σ 2 d d x e − x 2 / 4 σ 2 , then integrate by parts:

G ′ ( k ) = − ∫ − ∞ ∞ x e − x 2 / 4 σ 2 sin ⁡ ( k x ) d x = 2 σ 2 [ e − x 2 / 4 σ 2 sin ⁡ ( k x ) ] − ∞ ∞ − 2 σ 2 k G ( k ) = − 2 σ 2 k G ( k ) . (7.104)

The end term vanishes because the bell does. Dividing by G and integrating, ln ⁡ ( G ) = − σ 2 k 2 + C , so G ( k ) = G ( 0 ) e − σ 2 k 2 with G ( 0 ) = ∫ e − x 2 / 4 σ 2 d x = 2 σ π . Therefore

g ( k ) = ( 2 π σ 2 ) − 1 / 4 σ π e − σ 2 k 2 . (7.105)

The transform of a bell is a bell: the tighter the particle is held (small σ ), the wider its momentum recipe (Figure 7.17).

TheoremUncertainty of the Gaussian

Measure each spread by its standard deviation. From | ψ | 2 ∝ e − x 2 / 2 σ 2 , Δ x = σ . The probability of each k is 2 π | g ( k ) | 2 , and | g | 2 ∝ e − 2 σ 2 k 2 = e − k 2 / 2 ( 1 / 2 σ ) 2 , so Δ k = 1 / 2 σ . Hence, whatever σ is,

Δ x Δ k = 1 2 → p = ℏ k Δ x Δ p = ℏ 2 . (7.106)

Heisenberg's uncertainty principle states that Δ x Δ p ≥ ℏ / 2 for every wave function; the Gaussian is the one that reaches the bound. It is the width–bandwidth tradeoff of the rectangular pulse, multiplied by ℏ .

Solving the free particle

For a free particle of mass m (no force), the wave function changes in time by Schrödinger's equation,

i ℏ ∂ ψ ∂ t = − ℏ 2 2 m ∂ 2 ψ ∂ x 2 , (7.107)

whose right side is the kinetic energy at work. A plane wave turning in time, ψ = e i ( k x − ω t ) , gives ℏ ω ψ on the left and ℏ 2 k 2 2 m ψ on the right, so it is a solution when

ℏ ω = ℏ 2 k 2 2 m ( E = p 2 2 m ) . (7.108)

Each plane wave turns at its own rate, so the solution for any starting wave function is

ψ ( x , t ) = ∫ − ∞ ∞ g ( k ) e i ( k x − ω t ) d k : (7.109)

take the starting recipe, let each wave turn, and add them back up. The transform has turned a partial differential equation into one multiplication for each k . Since | g ( k ) | never changes, the momentum probabilities stay fixed (no force), but the position spreads: the same Gaussian integrals give a bell of width

σ ( t ) = σ 1 + ( t / τ ) 2 , τ = 2 m σ 2 ℏ , (7.110)

because the faster parts of the recipe run ahead and the slower ones fall behind (Figure 7.18). For an electron held to σ = 1 Å, τ = 1.7 × 10 − 16 s, and its width doubles after 3 τ = 3 × 10 − 16 s.

7.5The Fourier Transform in Two and Three Dimensions

Video Lecture 21, Part 6: The Fourier Transform in 2D (24:44)

So far every function had one variable. A photograph is a function of two, the brightness f ( x , y ) at each point, and a field in space is a function of three. The transform carries over with one new idea: in more than one dimension, a pure wave has a direction.

Plane waves and the wave vector

On a line, the pure wave e i k x needs one number k : how fast it turns as you walk along x . On a surface it needs two, how fast it turns along x and how fast along y . Collect them in the wave vector k → = ( k x , k y ) and the point in r → = ( x , y ) ; the exponent is then a dot product:

e i ( k x x + k y y ) = e i k → ⋅ r → (7.111)

The crests are where the phase k → ⋅ r → is constant. Walking along a crest you move at right angles to k → , so the crests are parallel stripes across k → and the wave travels along k → . As on the line, the wavelength is

λ = 2 π | k → | : (7.112)

a longer wave vector means closer stripes. In space, k → = ( k x , k y , k z ) , k → ⋅ r → = k x x + k y y + k z z , and the crests are flat planes at right angles to k → , which is why e i k → ⋅ r → is called a plane wave. Light from a distant star, or a laser beam, arrives as plane waves.

DefinitionFourier Transform in Two and Three Dimensions

With the 1 2 π on the forward transform, as in the one-dimensional pair above, one factor for each direction:

g ( k x , k y ) = 1 ( 2 π ) 2 ∬ f ( x , y ) e − i ( k x x + k y y ) d x d y , f ( x , y ) = ∬ g ( k x , k y ) e i ( k x x + k y y ) d k x d k y , (7.113)
g ( k → ) = 1 ( 2 π ) 3 ∫ f ( r → ) e − i k → ⋅ r → d 3 r , f ( r → ) = ∫ g ( k → ) e i k → ⋅ r → d 3 k , (7.114)

with d 3 r = d x d y d z over all of space and d 3 k = d k x d k y d k z . Each is the one-dimensional transform done once along each axis.

The transform g is itself a picture, drawn on the k -plane: each point ( k x , k y ) is one plane wave, and | g | there is how much of that wave f contains. Near the centre k → is short and the stripes are wide: these waves carry the broad shapes of a picture. Far from the centre the stripes are fine: these carry its fine detail.

ExampleOne set of stripes

Find the transform of f ( x , y ) = cos ⁡ ( k → 0 ⋅ r → ) .

A cosine is two turning arrows:

cos ⁡ ( k → 0 ⋅ r → ) = 1 2 e i k → 0 ⋅ r → + 1 2 e − i k → 0 ⋅ r → . (7.115)

It contains two plane waves and nothing else, so its transform is zero everywhere except at two points: two dots, at + k → 0 and − k → 0 . Turning the stripes turns the dots, because each dot is the wave vector itself; crowding the stripes together moves the dots away from the centre.

ExampleCleaning a striped portrait

A regular pattern of stripes, such as a scanner or electrical interference can leave, is laid across Fourier's portrait. Remove the stripes without touching the face.

The striped picture is the face plus one cosine of stripes. In its transform (Figure 7.20, middle) the face is a glow at the centre, since a face is mostly broad, slow changes, and the stripes are two bright dots standing apart from everything else. Set those two plane waves to zero, covering the two dots and changing nothing else, and transform back: every stripe is gone and the face is untouched, because the face had almost nothing at those two points. Image programs remove regular patterns this way, for example the dots of a printed photograph when it is scanned.

Light through an opening

Video Lecture 21, Part 7: Light Through an Opening (30:29)

Diffraction is the bending and spreading of waves after they pass through an opening: a wide opening lets light go on almost straight, a narrow one (close to the wavelength λ ) spreads it in all directions. Every point of the opening sends out its own wave (Huygens). Toward a far screen in the direction θ , the wave from a point at height x travels an extra path x sin ⁡ ( θ ) , which turns its phase by k 0 x sin ⁡ ( θ ) with k 0 = 2 π / λ . Adding the waves from all points, weighted by the opening A ( x ) (one where light passes, zero where it is blocked), gives the diffraction formula for a far screen:

amplitude ( θ ) ∝ ∫ A ( x ) e − i k 0 x sin ⁡ ( θ ) d x . (7.116)

With k x = k 0 sin ⁡ ( θ ) this is ∫ A ( x ) e − i k x x d x = 2 π g ( k x ) : the Fourier transform of the opening, each direction being one wave number. For an opening A ( x , y ) the screen shows the two-dimensional transform,

amplitude ∝ ∬ A ( x , y ) e − i ( k x x + k y y ) d x d y , (7.117)

and the eye sees its square, the intensity.

ExampleA square and a round opening

A square opening of width w is a pulse in x times a pulse in y , so its amplitude is the pulse's sinc in each direction,

amplitude ∝ sin ⁡ ( k x w / 2 ) k x ⋅ sin ⁡ ( k y w / 2 ) k y , (7.118)

large only near the two axes: a cross of spots (Figure 7.21). It is dark where k x w = 2 π m , that is at sin ⁡ ( θ ) = m λ / w : a smaller opening spreads the pattern wider. A round opening of diameter D is the same in every direction, so its pattern is a disc and rings (the Airy pattern), with the first dark ring at sin ⁡ ( θ ) = 1.22 λ / D . A telescope of diameter D therefore cannot separate two stars closer than about 1.22 λ / D .

RemarkA product splits

If f ( r → ) = f 1 ( x ) f 2 ( y ) f 3 ( z ) , the exponential splits the same way, e − i k → ⋅ r → = e − i k x x e − i k y y e − i k z z , and the triple integral becomes three one-dimensional transforms:

g ( k → ) = g 1 ( k x ) g 2 ( k y ) g 3 ( k z ) . (7.119)

For example, the Gaussian particle of Section 7.4 in space is a product, ψ ( r → ) = ψ ( x ) ψ ( y ) ψ ( z ) = ( 2 π σ 2 ) − 3 / 4 e − r 2 / 4 σ 2 , so its transform is g ( k x ) g ( k y ) g ( k z ) ∝ e − σ 2 | k → | 2 : a round bell in k -space. An atom, though, is round without being a product.

A round function

If f ( r → ) = f ( r ) depends only on the distance from the origin, the direction of k → does not matter. Point k → along the z axis, so that k → ⋅ r → = k r cos ⁡ θ , and use spherical coordinates (Chapter 5), d 3 r = r 2 sin ⁡ θ d r d θ d ϕ :

g ( k ) = 1 ( 2 π ) 3 ∫ 0 ∞ r 2 f ( r ) d r ∫ 0 2 π d ϕ ∫ 0 π e − i k r cos ⁡ θ sin ⁡ θ d θ . (7.120)

The ϕ integral gives 2 π , and with u = cos ⁡ θ , ∫ 0 π e − i k r cos ⁡ θ sin ⁡ θ d θ = ∫ − 1 1 e − i k r u d u = 2 sin ⁡ ( k r ) k r . Hence

g ( k ) = 1 2 π 2 k ∫ 0 ∞ r f ( r ) sin ⁡ ( k r ) d r : (7.121)

one radial integral, and a round function has a round transform.

ExampleHydrogen's electron in momentum space

The ground state of hydrogen is ψ ( r ) = e − r / a / π a 3 , with the Bohr radius a = 0.529 Å. Find its momentum recipe, and the typical speed of the electron.

It is normalised: 4 π ∫ 0 ∞ r 2 e − 2 r / a π a 3 d r = 4 a 3 ⋅ a 3 4 = 1 . By the radial formula,

g ( k ) = 1 2 π 2 k 1 π a 3 ∫ 0 ∞ r e − r / a sin ⁡ ( k r ) d r . (7.122)

Write sin ⁡ ( k r ) = Im e i k r and s = 1 a − i k ; integrating by parts, ∫ 0 ∞ r e − s r d r = 1 / s 2 , and

Im 1 s 2 = Im ( 1 / a + i k ) 2 ( 1 / a 2 + k 2 ) 2 = 2 k a 3 ( 1 + a 2 k 2 ) 2 ⇒ g ( k ) = a 3 / 2 π 5 / 2 ( 1 + a 2 k 2 ) 2 . (7.123)

The recipe falls to half its height at a k = 2 − 1 ≈ 0.64 , so its width in k is about 1 / a : a smaller atom has a wider spread of momenta. Weighted by the recipe, ⟨ k 2 ⟩ = 1 / a 2 , so p rms = ℏ / a and the electron moves at about

v = ℏ m a = 2.2 × 10 6   m/s ≈ c 137 . (7.124)

7.6The Fourier Series as an Eigenvalue Problem

Video Lecture 21, Part 9: Beyond Sines and Cosines (41:53)

Why can sines and cosines build any shape? It is not luck. It is the same fact as in Chapter 3: the eigenvectors of a symmetric matrix are perpendicular and form a basis. Here the matrix is a differential operator, and its eigenvectors are functions.

From eigenvectors to eigenfunctions

Recall Chapter 3. A symmetric matrix A ( A = A T ) has eigenvectors, A e → n = λ n e → n ; eigenvectors of different eigenvalues are perpendicular, and there are enough of them to build any vector:

v → = ∑ n c n e → n , c n = v → ⋅ e → n e → n ⋅ e → n . (7.125)

Now sample a function u ( x ) on 0 ≤ x ≤ L at N points x j = j h , h = L / ( N + 1 ) , with u = 0 at both ends. The list ( u 1 , … , u N ) is a vector, and the second derivative becomes a matrix acting on it:

d 2 u d x 2 | x j ≈ u j + 1 − 2 u j + u j − 1 h 2 = ( D u → ) j , D = 1 h 2 ( − 2 1 1 − 2 ⋱ ⋱ ⋱ 1 1 − 2 ) . (7.126)

D is symmetric. Its eigenvectors are sampled sines: with u j = sin ⁡ ( j θ ) , u j + 1 + u j − 1 − 2 u j = − 4 sin 2 ⁡ ( θ / 2 ) u j , and the end conditions require θ = n π / ( N + 1 ) . So

D e → n = μ n e → n , e → n = ( sin ⁡ n π x j L ) j , μ n = − 4 h 2 sin 2 ⁡ n π h 2 L   → h → 0   − ( n π L ) 2 . (7.127)

As N → ∞ the vectors become functions, the dot product ∑ j u j v j h becomes ∫ 0 L u v d x , and D becomes the operator d 2 d x 2 . Write ℒ = − d 2 d x 2 (the minus sign makes the eigenvalues positive; ℒ is the operator, L the length). The eigenvalue problem of the matrix becomes a differential equation with a condition at each end, the string fixed at both ends:

ℒ u n ( x ) = λ n u n ( x ) , u n ( 0 ) = u n ( L ) = 0 ⇒ u n ( x ) = sin ⁡ n π x L , λ n = ( n π L ) 2 , n = 1 , 2 , 3 , … (7.128)

The operator acting on an eigenfunction gives back the same function times a number, exactly as A e → n = λ n e → n : u n is an eigenfunction of ℒ , and λ n its eigenvalue.

TheoremWhy the eigenfunctions are perpendicular

If u and v vanish at both ends, integrating by parts twice gives ∫ 0 L u v ″ d x = ∫ 0 L u ″ v d x : the operator is symmetric, ∫ 0 L u ( ℒ v ) d x = ∫ 0 L ( ℒ u ) v d x . Apply it to two eigenfunctions, ℒ u n = λ n u n and ℒ u m = λ m u m :

λ m ∫ 0 L u n u m d x = ∫ 0 L u n ( ℒ u m ) d x = ∫ 0 L ( ℒ u n ) u m d x = λ n ∫ 0 L u n u m d x , (7.129)

hence

( λ n − λ m ) ∫ 0 L u n u m d x = 0 , (7.130)

so eigenfunctions of different eigenvalues are perpendicular, exactly as for a symmetric matrix.

There are infinitely many of them, one for each n , and they build any reasonable f on [ 0 , L ] with c n = 2 L ∫ 0 L f ( x ) sin ⁡ n π x L d x : the Fourier sine series. With the repeat condition u ( x + L ) = u ( x ) in place of fixed ends, the same operator has the eigenfunctions e i k n x , and the expansion is the complex Fourier series of this chapter (for complex functions the dot product is ∫ f g ∗ d x ).

Sturm–Liouville problems

The argument never used the special form of d 2 d x 2 , only its symmetry. A string whose mass per length w ( x ) changes along it vibrates by T u ″ = − ω 2 w ( x ) u ; heat in a bar whose material changes along it, the problem Sturm and Liouville studied in the 1830s, leads to the same kind of equation.

TheoremSturm–Liouville

Consider the operator

ℒ u = 1 w ( x ) [ − d d x ( p ( x ) d u d x ) + q ( x ) u ] , ℒ u n = λ n u n , a ≤ x ≤ b , (7.131)

with p > 0 , w > 0 and a condition at each end (for example u = 0 ). It is symmetric with the weight w , ∫ a b w u ( ℒ v ) d x = ∫ a b w ( ℒ u ) v d x . Then

  1. the eigenvalues λ n are real;

  2. eigenfunctions of different eigenvalues are perpendicular with the weight w : ∫ a b w u n u m d x = 0 for n ≠ m ;

  3. there are infinitely many, and they build any f with ∫ a b w f 2 d x finite:

    f ( x ) = ∑ n c n u n ( x ) , c n = ∫ a b w f u n d x ∫ a b w u n 2 d x . (7.132)

For piecewise smooth f the expansion converges at every point of continuity, and to the midpoint at a jump, as in the Dirichlet theorem.

The Fourier series is the simplest case, p = w = 1 , q = 0 . The weight is the analogue of a dot product in which some components count more than others.

ExampleA string heavier at one end

A string on 0 ≤ x ≤ 1 , fixed at both ends, with mass per length w ( x ) = 1 + 3 x : its modes solve ℒ u n = − 1 w u n ″ = λ n u n ( p = 1 , q = 0 ). They are not sines, since they crowd towards the heavy end (Figure 7.24), and the ordinary integral of two of them is not zero: with each mode scaled so that ∫ 0 1 w u n 2 d x = 1 , numerically ∫ 0 1 u 1 u 2 d x = 0.081 . With the weight it is: ∫ 0 1 w u 1 u 2 d x = 0 . The weight is not optional.

RemarkThe family

The same theorem covers the special functions of later chapters: Legendre polynomials (Chapter 9) for problems with spherical symmetry, with w = 1 on [ − 1 , 1 ] ; Bessel functions for drums and pipes, with w = x ; Hermite functions for the quantum oscillator. Each comes from its own operator, and each builds any shape with the same recipe. For example | x | = 1 2 P 0 ( x ) + 5 8 P 2 ( x ) − 3 16 P 4 ( x ) + ⋯ on [ − 1 , 1 ] . Expanding in eigenfunctions is also how Chapter 10 solves partial differential equations.

7.7Where Fourier Analysis Is Used

The single idea of this chapter — that a function can be rebuilt from sines and cosines, or from complex exponentials — is one of the most widely used in all of physics and engineering. The reason is that the basis functions e i k x are the natural language of anything that oscillates, and of the linear equations that govern waves, heat and quantum systems.

  • Solving partial differential equations. Fourier's original motive was heat flow. Because each mode e i k x evolves independently under the heat, wave and Schrödinger equations, expanding the initial state in modes turns a partial differential equation into a set of ordinary ones. This is the method of Chapter 10.

  • Signal processing. A signal's Fourier coefficients are its frequency content. Filtering, noise removal and compression are all operations on that spectrum, as the low-pass filter of this chapter showed.

  • Spectroscopy and optics. The rectangular-pulse and Lorentzian transforms computed above are exactly the line shapes measured in spectroscopy: the width of a spectral line and the lifetime of the state that produced it are a Fourier transform pair.

  • Quantum mechanics. Position and momentum wavefunctions are Fourier transforms of one another. The width–bandwidth tradeoff seen in the pulse example — narrow in x means wide in k — is, with p = ℏ k , the Heisenberg uncertainty principle.

  • Normal modes. The harmonics of a Fourier series are the standing waves of a vibrating string or air column; their frequencies ν n = n / L are why instruments have a well-defined pitch.

Remark

The width–bandwidth tradeoff deserves a second mention because it recurs under so many names. A pulse of duration Δ t has a spectrum of width Δ ω ∼ 1 / Δ t . In signal processing this limits how sharply a filter can act; in spectroscopy it is the natural linewidth; in quantum mechanics it is Δ x Δ p ≳ ℏ . They are all one statement about Fourier pairs: you cannot make a function narrow in both domains at once.
