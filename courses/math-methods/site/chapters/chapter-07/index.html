7.1Even and Odd Functions

Video Lecture 20, Part 2: Even and Odd Functions (4:39)

DefinitionEven and Odd Functions

  • A function f ( x ) is said to be even if

    f ( − x ) = f ( x ) . (7.1)

  • A function f ( x ) is said to be odd if

    f ( − x ) = − f ( x ) . (7.2)

Properties of Integrals over Symmetric Limits:

If  f ( x )  is even: ∫ − L / 2 L / 2 f ( x ) d x = 2 ∫ 0 L / 2 f ( x ) d x , If  f ( x )  is odd: ∫ − L / 2 L / 2 f ( x ) d x = 0. (7.3)
Remark

In general, any function f ( x ) can be expressed as the sum of an even and an odd function:

f ( x ) = 1 2 [ f ( x ) + f ( − x ) ] + 1 2 [ f ( x ) − f ( − x ) ] . (7.4)

The first term is the even part of f ( x ) , and the second term is the odd part.

7.2Periodic Functions and Fourier Series

Video Lecture 20, Part 3: Periodic Functions and the Waves That Fit (9:13)

DefinitionPeriodic Function

A function f ( x ) is said to be periodic with period L > 0 if

f ( x + L ) = f ( x ) for all  x . (7.5)

The smallest positive L satisfying this relation is called the fundamental period.

Remark

Common periodic functions include

sin ( 2 π x L ) , cos ( 2 π x L ) , e i 2 π x L , (7.6)

all sharing the same fundamental period L .

DefinitionAverage Value of a Function

For a periodic function f ( x ) of period L , the average value (or mean value) of the function over one period is defined as

⟨ f ⟩ = 1 L ∫ − L / 2 L / 2 f ( x ) d x . (7.7)

7.2.1Fundamental Periodic Basis

For the exponential function e i k x to have period L ,

e i k ( x + L ) = e i k x ⇒ e i k L = 1. (7.8)

Since e i 2 π n = 1 for integers n , we have

k n = 2 π n L , n = 0 , ± 1 , ± 2 , … (7.9)

Thus, the functions

e i k n x = e i 2 π n x L (7.10)

form a complete orthogonal set over one period.

RemarkOrthogonality
∫ − L / 2 L / 2 e i k m x e − i k n x d x = L δ m n . (7.11)

For n ≠ m the product e i ( k m − k n ) x turns a whole number of times in one period, so its real and imaginary parts have as much area above the axis as below; for n = m it is 1 , with area L .

7.2.2Complex Fourier Series

Video Lecture 20, Part 4: The Complex Fourier Series (13:57)

DefinitionComplex Fourier Series

A periodic function f ( x ) of period L can be represented as

f ( x ) = ∑ n = − ∞ ∞ c n e i k n x , k n = 2 π n L , (7.12)

where the coefficients are

c n = 1 L ∫ − L / 2 L / 2 f ( x ) e − i k n x d x . (7.13)

Each coefficient c n gives the contribution of the wave e i k n x to f ; the list of all of them is the spectrum of f .

Starting from f ( x ) = ∑ c n e i k n x , multiply by e − i k m x and integrate:

∫ − L / 2 L / 2 f ( x ) e − i k m x d x = ∑ n c n ∫ − L / 2 L / 2 e i ( k n − k m ) x d x = L c m , (7.14)

by orthogonality. Hence,

c m = 1 L ∫ − L / 2 L / 2 f ( x ) e − i k m x d x . (7.15)
Remark

For a real-valued function f ( x ) , the complex coefficients satisfy

c − n = c n ∗ . (7.16)

7.2.3Real Form of the Fourier Series

Video Lecture 20, Part 5: The Real Form and Its Coefficients (19:17)

TheoremReal Form of the Fourier Series
f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ( 2 π n x L ) + b n sin ( 2 π n x L ) ] . (7.17)

Starting from the complex Fourier series.

We begin with the complex form of the Fourier series for a periodic function f ( x ) of period L :

f ( x ) = ∑ n = − ∞ ∞ c n e i k n x , where  k n = 2 π n L . (7.18)

We separate the n = 0 term and rearrange positive and negative indices:

f ( x ) = c 0 + ∑ n = 1 ∞ ( c n e i k n x + c − n e − i k n x ) . (7.19)

Using c − n = c n ∗ , we have

f ( x ) = c 0 + ∑ n = 1 ∞ ( c n e i k n x + c n ∗ e − i k n x ) . (7.20)

Expressing in terms of sine and cosine.

Let

c 0 = a 0 2 c n = 1 2 ( a n − i b n ) , c n ∗ = 1 2 ( a n + i b n ) , (7.21)

where a n and b n are real numbers.

Then

c n e i k n x + c n ∗ e − i k n x = 1 2 [ ( a n − i b n ) ( cos ⁡ k n x + i sin ⁡ k n x ) + ( a n + i b n ) ( cos ⁡ k n x − i sin ⁡ k n x ) ] = a n cos ⁡ k n x + b n sin ⁡ k n x . (7.22)

Hence the series becomes

f ( x ) = a 0 2 + ∑ n = 1 ∞ ( a n cos ⁡ k n x + b n sin ⁡ k n x ) . (7.23)

Thus the final real form of the Fourier series is

f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ⁡ ( 2 π n x L ) + b n sin ⁡ ( 2 π n x L ) ] . (7.24)
Remark

  • a 0 2 : average (DC component) of f ( x ) ,

  • a n : amplitude of the cosine component,

  • b n : amplitude of the sine component,

  • frequency of the n -th harmonic: f n = n L .

TheoremFourier Coefficients

For f ( x ) of period L :

a 0 = 2 L ∫ − L / 2 L / 2 f ( x ) d x , a n = 2 L ∫ − L / 2 L / 2 f ( x ) cos ( 2 π n x L ) d x , b n = 2 L ∫ − L / 2 L / 2 f ( x ) sin ( 2 π n x L ) d x . (7.25)

Multiply both sides of the Fourier expansion by cos ( 2 π m x L ) and integrate over one period:

∫ − L / 2 L / 2 f ( x ) cos ( 2 π m x L ) d x = ∫ − L / 2 L / 2 [ a 0 2 + ∑ n = 1 ∞ ( a n cos 2 π n x L + b n sin 2 π n x L ) ] cos ( 2 π m x L ) d x . (7.26)

Using the orthogonality relations:

∫ − L / 2 L / 2 cos ( 2 π m x L ) d x = 0 , ∫ − L / 2 L / 2 cos ( 2 π n x L ) cos ( 2 π m x L ) d x = L 2 δ m n , ∫ − L / 2 L / 2 sin ( 2 π n x L ) cos ( 2 π m x L ) d x = 0 , (7.27)

all terms vanish except the one where n = m :

∫ − L / 2 L / 2 f ( x ) cos ( 2 π m x L ) d x = a m L 2 . (7.28)

Hence,

a m = 2 L ∫ − L / 2 L / 2 f ( x ) cos ( 2 π m x L ) d x . (7.29)

Similarly, multiplying the Fourier series by sin ( 2 π m x L ) and integrating gives

b m = 2 L ∫ − L / 2 L / 2 f ( x ) sin ( 2 π m x L ) d x . (7.30)

Finally, integrating both sides of the Fourier expansion over one period. Since the integrals of all sine and cosine terms vanish over a full period, only the constant term a 0 2 survives:

∫ − L / 2 L / 2 f ( x ) d x = ∫ − L / 2 L / 2 a 0 2 d x = a 0 2 L . (7.31)

Hence,

a 0 = 2 L ∫ − L / 2 L / 2 f ( x ) d x , (7.32)

consistent with the general formula for a n at n = 0 . Note that it is a 0 2 , not a 0 , that equals the average value (mean) of f ( x ) over one period; writing the constant term as a 0 2 is precisely what lets the single formula a n = 2 L ∫ f cos ⁡ ( 2 π n x / L ) d x cover the case n = 0 .

7.2.4Dirichlet Conditions and Convergence of Fourier Series

Video Lecture 20, Part 6: When It Works: Dirichlet (25:11)

DefinitionDirichlet Conditions

A periodic function f ( x ) of period L can be represented by a Fourier series (without modification) on the interval [ − L 2 , L 2 ] if it satisfies the following conditions:

  1. f ( x ) is single-valued and piecewise continuous within one period.

  2. f ( x ) has a finite number of finite discontinuities.

  3. f ( x ) has a finite number of maxima and minima within one period.

  4. The integral of its absolute value over one period is finite:

    ∫ − L / 2 L / 2 | f ( x ) | d x < ∞ . (7.33)
TheoremConvergence of the Fourier Series

If f ( x ) satisfies the Dirichlet conditions and has period L , then its Fourier series

f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ( 2 π n x L ) + b n sin ( 2 π n x L ) ] (7.34)

converges as follows:

  • At every point where f ( x ) is continuous, the Fourier series converges to f ( x ) .

  • At each point of discontinuity x 0 , the Fourier series converges to the midpoint of the jump:

    f series ( x 0 ) = 1 2 [ f ( x 0 + ) + f ( x 0 − ) ] . (7.35)

7.2.5Meaning and Interpretation of the Fourier Series

Video Lecture 20, Part 7: What the Harmonics Mean (27:43)

The Fourier series allows us to express any sufficiently smooth periodic function f ( x ) (with period L ) as a sum of simple oscillatory components — sine and cosine waves. Mathematically,

f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ⁡ ( k n x ) + b n sin ⁡ ( k n x ) ] , k n = 2 π n L . (7.36)

Each term in the sum represents a harmonic component (or mode) of the signal.

DefinitionHarmonic Component

The n -th term in the Fourier series,

u n ( x ) = a n cos ⁡ ( k n x ) + b n sin ⁡ ( k n x ) , (7.37)

is called the n -th harmonic; the two waves e ± i k n x of the complex series are its two halves. It makes n whole turns in one period. If the variable is a position x , the period L is the wavelength λ , and

k n = 2 π n λ (wave number) ; (7.38)

if the variable is a time t , the period is T , and

ω n = 2 π n T (angular frequency) , ν n = n T (frequency) . (7.39)

Thus,

u 0 ( x ) = a 0 2 , (average or DC component) u 1 ( x ) = a 1 cos ⁡ ( k 1 x ) + b 1 sin ⁡ ( k 1 x ) , (fundamental harmonic) u 2 ( x ) = a 2 cos ⁡ ( 2 k 1 x ) + b 2 sin ⁡ ( 2 k 1 x ) , (second harmonic) u N ( x ) = a N cos ⁡ ( N k 1 x ) + b N sin ⁡ ( N k 1 x ) , ( N -th harmonic) . (7.40)

Each harmonic contributes a specific frequency, amplitude, and phase to the total waveform. The original function f ( x ) is reconstructed by summing all harmonic components:

f ( x ) = u 0 ( x ) + u 1 ( x ) + u 2 ( x ) + ⋯ = ∑ n = 0 ∞ u n ( x ) . (7.41)

As more harmonics are included, the approximation of f ( x ) becomes more accurate. Lower harmonics ( n = 0 , 1 , 2 ) describe the overall shape, while higher harmonics capture finer details and sharp transitions.

Applications in Signal Processing

DefinitionLow-Pass Filter

A low-pass filter removes high-frequency (large n ) components from a signal, keeping only low-frequency terms:

f filtered ( x ) = ∑ n = 0 N u n ( x ) , (7.42)

where N sets the cutoff frequency.

RemarkApplications

  • Signal processing: Decompose and reconstruct signals by frequency content.

  • Noise reduction: Remove unwanted high-frequency components using low-pass filtering.

  • Data compression: Approximate a signal using only the dominant harmonics.

  • Physics: Analyze normal modes in vibrating strings, membranes, and quantum systems.

ExampleSquare step on [ − π , π ]

Find the Fourier series of

f ( x ) = { 0 , − π < x < 0 , 1 , 0 < x < π , (period  2 π ) . (7.43)

Fourier form on [ − π , π ] . With period L = 2 π , the series is

f ( x ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ⁡ ( n x ) + b n sin ⁡ ( n x ) ] , (7.44)

where, from the coefficient formulas with L = 2 π so that 2 L = 1 π ,

a 0 = 1 π ∫ − π π f ( x ) d x , a n = 1 π ∫ − π π f ( x ) cos ⁡ ( n x ) d x , b n = 1 π ∫ − π π f ( x ) sin ⁡ ( n x ) d x . (7.45)

The unknowns are a 0 , a n and b n : once they are found, the expansion is known, each coefficient giving the contribution of its harmonic.

Solution.

Step 1: a 0 . The constant term of the series is a 0 2 , so we expect it to equal the average of f , namely 1 2 .

a 0 = 1 π ∫ − π π f ( x ) d x = 1 π ∫ 0 π 1 d x = 1 ⇒ a 0 2 = 1 2 . (7.46)

Step 2: a n (all n ≥ 1 ).

a n = 1 π ∫ 0 π cos ⁡ ( n x ) d x = 1 π ⋅ sin ⁡ ( n x ) n | 0 π = 0. (7.47)

Step 3: b n (all n ≥ 1 ).

b n = 1 π ∫ 0 π sin ⁡ ( n x ) d x = 1 π ⋅ − cos ⁡ ( n x ) n | 0 π = 1 n π ( 1 − cos ⁡ ( n π ) ) = 1 − ( − 1 ) n n π . (7.48)

Hence

b n = { 0 , n   even , 2 n π , n   odd . (7.49)

Result.

f ( x ) = 1 2 + 2 π ( sin ⁡ x + sin ⁡ 3 x 3 + sin ⁡ 5 x 5 + ⋯ ) (7.50)

(i.e., the sum runs over odd n ). At the jump points x ≡ 0 , π   ( mod   2 π ) , the series converges to the average 1 2 (Dirichlet’s theorem).

ExamplePeriodic half-ramp

Let

f ( t ) = { 0 , − T 2 < t < 0 , t , 0 < t < T 2 , extended periodically with period  T . (7.59)

We find its real Fourier series

f ( t ) = a 0 2 + ∑ n = 1 ∞ [ a n cos ⁡ ( ω n t ) + b n sin ⁡ ( ω n t ) ] , ω n = 2 π n T . (7.60)

The variable is now time: x → t , the period L → T , and the wave number k n becomes the angular frequency ω n . The unknowns are a 0 , a n and b n .

Hence the DC term is a 0 / 2 = T / 8 .

∫ t cos ⁡ ( ω n t ) d t = t sin ⁡ ( ω n t ) ω n + cos ⁡ ( ω n t ) ω n 2 . (7.63)

Therefore

a n = 2 T [ t sin ⁡ ( ω n t ) ω n + cos ⁡ ( ω n t ) ω n 2 ] 0 T / 2 = 2 T [ ( T / 2 ) sin ⁡ ( ω n T / 2 ) ω n + cos ⁡ ( ω n T / 2 ) − 1 ω n 2 ] . (7.64)

a n = 2 T ⋅ ( − 1 ) n − 1 ω n 2 = T 2 π 2 n 2 [ ( − 1 ) n − 1 ] . (7.65)

Hence

a n = 0   for even  n , a n = − T π 2 n 2   for odd  n . (7.66)

∫ t sin ⁡ ( ω n t ) d t = − t cos ⁡ ( ω n t ) ω n + sin ⁡ ( ω n t ) ω n 2 . (7.68)

Thus

b n = 2 T [ − t cos ⁡ ( ω n t ) ω n + sin ⁡ ( ω n t ) ω n 2 ] 0 T / 2 = − 2 T ⋅ ( T / 2 ) cos ⁡ ( ω n T / 2 ) ω n = ( − 1 ) n + 1 ω n = ( − 1 ) n + 1 T 2 π n . (7.69)

ExampleComplex Fourier Series of a Periodic Ramp Function f ( x ) = x (period L )

Consider a spatially periodic function

f ( x ) = x , − L 2 < x < L 2 , (7.71)

which repeats every interval of length L . This represents a periodic ramp waveform, analogous to a sawtooth pattern in signal processing.

We want its series in complex form, f ( x ) = ∑ n = − ∞ ∞ c n e i k n x ; the unknowns are c 0 and c n .

Solution.

For a periodic function f ( x ) of period L , the complex Fourier coefficients are

c n = 1 L ∫ − L / 2 L / 2 f ( x ) e − i k n x d x , where  k n = 2 π n L . (7.72)

Substitute f ( x ) = x :

c n = 1 L ∫ − L / 2 L / 2 x e − i k n x d x . (7.73)

Step 2. Integration by parts.

Let

u = x , d v = e − i k n x d x ⇒ d u = d x , v = e − i k n x − i k n = i k n e − i k n x . (7.74)

Then

c n = 1 L [ u v ] − L / 2 L / 2 − 1 L ∫ − L / 2 L / 2 v d u = i L k n [ x e − i k n x ] − L / 2 L / 2 − i L k n ∫ − L / 2 L / 2 e − i k n x d x . (7.75)

Step 3. Simplify the second term.

The exponential integral gives

∫ − L / 2 L / 2 e − i k n x d x = 2 sin ⁡ ( k n L / 2 ) k n = 2 sin ⁡ ( π n ) k n = 0 , (7.76)

since sin ⁡ ( π n ) = 0 for all integer n . Hence, only the boundary term contributes.

Step 4. Evaluate the boundary term.

c n = i L k n [ L 2 e − i k n L / 2 − ( − L 2 ) e i k n L / 2 ] = i 2 k n ( e − i π n + e i π n ) = i k n cos ⁡ ( π n ) . (7.77)

Using cos ⁡ ( π n ) = ( − 1 ) n , we have

c n = i k n ( − 1 ) n = i L 2 π n ( − 1 ) n , n ≠ 0. (7.78)

Step 5. DC (zero-frequency) coefficient.

c 0 = 1 L ∫ − L / 2 L / 2 x d x = 0 , (7.79)

since f ( x ) = x is an odd function and its average over one period is zero.

Step 6. Complete complex Fourier series.

f ( x ) = ∑ n = − ∞ n ≠ 0 ∞ i L 2 π n ( − 1 ) n e i k n x , k n = 2 π n L . (7.80)

Interpretation.

  • The amplitude of each harmonic decreases as 1 / n , meaning higher-frequency components contribute less to the total waveform.

  • Because f ( x ) is an odd function, the coefficients c n are purely imaginary ( c − n = c n ∗ ), corresponding to a sine-only spectrum.

  • Truncating the series to a few terms yields a smooth approximation of the ramp—analogous to applying a low-pass filter that removes sharp discontinuities.

7.3Fourier Transform

Video Lecture 21, Part 1: From Series to Transform (0:00)

The Fourier transform can be viewed as the limiting case of the complex Fourier series when the period L → ∞ . In this limit, the function f ( x ) becomes nonperiodic, and the discrete spectrum of wave numbers becomes continuous.

Transition from Discrete to Continuous Spectrum

Consider a periodic function f ( x ) with period L :

f ( x ) = ∑ n = − ∞ ∞ c n e i k n x , k n = 2 π n L . (7.81)

When L → ∞ , the spacing between successive wave numbers becomes infinitesimal:

Δ k = k n + 1 − k n = 2 π L ⇒ Δ k → 0. (7.82)

The discrete index n is replaced by a continuous variable k :

∑ n = − ∞ ∞ ⟶ L 2 π ∫ − ∞ ∞ d k . (7.83)
DefinitionFourier Coefficient in Continuous Limit

Let

g ( k ) = L 2 π c n with k = k n . (7.84)

Then g ( k ) becomes a continuous function that represents the spectral amplitude density of f ( x ) .

Substituting c n = 2 π L g ( k n ) = g ( k n ) Δ k into the series and taking the limit L → ∞ :

f ( x ) = ∑ n = − ∞ ∞ c n e i k n x = ∑ n = − ∞ ∞ g ( k n ) e i k n x Δ k → L → ∞ ∫ − ∞ ∞ g ( k ) e i k x d k . (7.85)
DefinitionFourier Transform (F.T.) and Inverse Transform
f ( x ) = ∫ − ∞ ∞ g ( k ) e i k x d k , (Inverse Fourier Transform) g ( k ) = 1 2 π ∫ − ∞ ∞ f ( x ) e − i k x d x , (Fourier Transform). (7.86)
Remark

  • f ( x ) : function in the spatial (time) domain.

  • g ( k ) : its representation in the frequency (wave number) domain.

  • The transform pair is symmetric up to the normalization factor 1 / 2 π .

DefinitionFourier Transform (F.T.) and Inverse Transform in the Time Domain
f ( t ) = ∫ − ∞ ∞ g ( ω ) e i ω t d ω , (Inverse Fourier Transform) g ( ω ) = 1 2 π ∫ − ∞ ∞ f ( t ) e − i ω t d t , (Fourier Transform). (7.87)

ExampleRectangular pulse of width 2 a

Let

f ( x ) = { 1 , − a < x < a , 0 , otherwise , a > 0. (7.88)

This is a nonperiodic rectangular pulse centered at the origin with total width 2 a and unit height. The unknown is its Fourier transform g ( k ) : which waves the pulse contains, and how much of each.

We use the transform pair

g ( k ) = 1 2 π ∫ − ∞ ∞ f ( x ) e − i k x d x , f ( x ) = ∫ − ∞ ∞ g ( k ) e i k x d k . (7.89)

Solution.

g ( k ) = 1 2 π ∫ − a a e − i k x d x . (7.90)

Step 2. Evaluate the integral.

∫ e − i k x d x = e − i k x − i k ⇒ ∫ − a a e − i k x d x = e − i k a − e i k a − i k = 2 sin ⁡ ( k a ) k . (7.91)

Step 3. Simplify and express the result.

g ( k ) = 1 2 π ⋅ 2 sin ⁡ ( k a ) k = 1 π sin ⁡ ( k a ) k = a π sinc ( a k ) , sinc ( u ) = sin ⁡ u u . (7.92)

At k = 0 , we take the limit g ( 0 ) = lim k → 0 a π sinc ( a k ) = a π .

Key features.

  • g ( k ) is real, even, and has zeros at k = ± n π / a for n = 1 , 2 , 3 , … .

  • The main lobe width Δ k ∼ 2 π / a — increasing a (wider pulse) narrows the spectrum.

  • The transform pair summarizes the width–bandwidth tradeoff: a narrow function in k -space corresponds to a wide function in x -space and vice versa.

g ( ω ) = 1 2 π [ ∫ − ∞ 0 e a t e − i ω t d t + ∫ 0 ∞ e − a t e − i ω t d t ] . (7.95)

Step 2. Evaluate each integral.

∫ 0 ∞ e − a t e − i ω t d t = 1 a + i ω , ∫ − ∞ 0 e a t e − i ω t d t = 1 a − i ω . (7.96)

Step 3. Combine the results:

g ( ω ) = 1 2 π ( 1 a + i ω + 1 a − i ω ) = 1 π a a 2 + ω 2 . (7.97)

Thus, the Fourier transform of e − a | t | is

g ( ω ) = 1 π a a 2 + ω 2 (7.98)

which is known as the Lorentzian function.

Shape of g ( ω ) :

As a increases, g ( ω ) becomes broader and shorter; as a decreases, it becomes narrower and taller.

7.4A Quantum Particle in Fourier Space

The momentum-space wave function

In quantum mechanics, the state of a particle is described by a wave function ψ ( x ) ; the quantity | ψ ( x ) | 2 d x is the probability of finding the particle between x and x + d x . According to de Broglie, a plane wave e i k x has the definite momentum p = ℏ k , where ℏ = h / 2 π = 1.055 × 10 − 34 J s. Expanding ψ in plane waves,

ψ ( x ) = ∫ − ∞ ∞ g ( k ) e i k x d k , (7.99)

therefore expresses the state in terms of states of definite momentum. The Fourier transform g ( k ) is the momentum-space wave function, and | g ( k ) | 2 is proportional to the probability that the particle has momentum ℏ k .

A free particle (one on which no force acts) localized near the origin is described by a Gaussian wave packet,

ψ ( x ) = A e − x 2 / 4 σ 2 , A = ( 2 π σ 2 ) − 1 / 4 . (7.100)

Its position probability density, | ψ ( x ) | 2 = A 2 e − x 2 / 2 σ 2 , is a normal distribution centred at x = 0 .

ExampleMomentum-space wave function of a Gaussian wave packet

Find the momentum-space wave function of the Gaussian wave packet

ψ ( x ) = A e − x 2 / 4 σ 2 , A = ( 2 π σ 2 ) − 1 / 4 . (7.101)

We use the transform pair

g ( k ) = 1 2 π ∫ − ∞ ∞ ψ ( x ) e − i k x d x , ψ ( x ) = ∫ − ∞ ∞ g ( k ) e i k x d k . (7.102)

The unknown is g ( k ) : how much of each momentum ℏ k the packet contains.

Solution.

Step 1. Write the transform.

g ( k ) = A 2 π ∫ − ∞ ∞ e − x 2 / 4 σ 2 e − i k x d x . (7.103)

Step 2. Remove the odd part. Write e − i k x = cos ⁡ ( k x ) − i sin ⁡ ( k x ) . The Gaussian is even and sin ⁡ ( k x ) is odd, so their product integrates to zero over ( − ∞ , ∞ ) :

g ( k ) = A 2 π G ( k ) , G ( k ) = ∫ − ∞ ∞ e − x 2 / 4 σ 2 cos ⁡ ( k x ) d x . (7.104)

Step 3. Find a differential equation for G . Differentiate under the integral sign with respect to k :

G ′ ( k ) = − ∫ − ∞ ∞ x e − x 2 / 4 σ 2 sin ⁡ ( k x ) d x . (7.105)

Since d d x e − x 2 / 4 σ 2 = − x 2 σ 2 e − x 2 / 4 σ 2 , we may write x e − x 2 / 4 σ 2 = − 2 σ 2 d d x e − x 2 / 4 σ 2 and integrate by parts:

G ′ ( k ) = 2 σ 2 ∫ − ∞ ∞ ( d d x e − x 2 / 4 σ 2 ) sin ⁡ ( k x ) d x = 2 σ 2 [ e − x 2 / 4 σ 2 sin ⁡ ( k x ) ] − ∞ ∞ − 2 σ 2 k ∫ − ∞ ∞ e − x 2 / 4 σ 2 cos ⁡ ( k x ) d x . (7.106)

The boundary term is zero because the Gaussian vanishes at ± ∞ , and the last integral is G ( k ) :

G ′ ( k ) = − 2 σ 2 k G ( k ) . (7.107)

Step 4. Solve the differential equation. Separate the variables and integrate from 0 to k :

d G G = − 2 σ 2 k d k ⇒ ln ⁡ G ( k ) G ( 0 ) = − σ 2 k 2 ⇒ G ( k ) = G ( 0 ) e − σ 2 k 2 . (7.108)

Step 5. Find G ( 0 ) . Substitute x = 2 σ u , d x = 2 σ d u , and use the Gaussian integral ∫ − ∞ ∞ e − u 2 d u = π :

G ( 0 ) = ∫ − ∞ ∞ e − x 2 / 4 σ 2 d x = 2 σ ∫ − ∞ ∞ e − u 2 d u = 2 σ π . (7.109)

Result.

g ( k ) = A 2 π 2 σ π e − σ 2 k 2 ⇒ g ( k ) = A σ π e − σ 2 k 2 . (7.110)

Key features.

  • The Fourier transform of a Gaussian is again a Gaussian, centred at k = 0 .

  • σ is in the denominator of the exponent of ψ and in the numerator of the exponent of g : a packet that is narrower in position (smaller σ ) has a broader distribution of momenta (Figure 7.17).

The uncertainty relation

Video Lecture 21, Part 5: Uncertainty, and the Spreading Electron (20:24)

The width of a probability density P ( x ) is measured by its standard deviation Δ x :

⟨ x n ⟩ = ∫ x n P ( x ) d x ∫ P ( x ) d x , ( Δ x ) 2 = ⟨ x 2 ⟩ − ⟨ x ⟩ 2 . (7.111)

For a normal distribution P ( x ) ∝ e − x 2 / 2 s 2 , ⟨ x ⟩ = 0 by symmetry, and integration by parts gives ∫ x 2 e − x 2 / 2 s 2 d x = s 2 ∫ e − x 2 / 2 s 2 d x , so ⟨ x 2 ⟩ = s 2 and

P ( x ) ∝ e − x 2 / 2 s 2 ⇒ Δ x = s . (7.112)

The standard deviation of a Gaussian can therefore be read off its exponent. Another common measure of width is the full width at half maximum (FWHM), the distance between the two points at which P falls to half its peak value. For the normal distribution, e − x 2 / 2 s 2 = 1 2 gives x = ± s 2 ln ⁡ 2 , so FWHM = 2 2 ln ⁡ 2 s ≈ 2.355 s .

In quantum mechanics, Δ x is the standard deviation of | ψ ( x ) | 2 , and the momentum uncertainty is Δ p = ℏ Δ k , where Δ k is the standard deviation of | g ( k ) | 2 . The Heisenberg uncertainty principle states that Δ x Δ p ≥ ℏ / 2 for every wave function.

ExampleUncertainty relation for the Gaussian wave packet

Find Δ x , Δ p and the product Δ x Δ p for the Gaussian wave packet, whose position and momentum wave functions are

Solution.

Step 1. Position. Squaring doubles the exponent:

| ψ ( x ) | 2 = A 2 e − x 2 / 2 σ 2 . (7.114)

This is the normal form with s = σ , so Δ x = σ .

Step 2. Momentum. Squaring g ( k ) ,

| g ( k ) | 2 = A 2 σ 2 π e − 2 σ 2 k 2 . (7.115)

Match the exponent to the normal form, 2 σ 2 k 2 = k 2 / 2 s 2 , which gives s 2 = 1 / 4 σ 2 . Hence Δ k = 1 / 2 σ and Δ p = ℏ Δ k = ℏ / 2 σ .

Step 3. Product.

Δ x Δ k = σ ⋅ 1 2 σ = 1 2 . (7.116)

Result.

Δ x = σ , Δ p = ℏ 2 σ , Δ x Δ p = ℏ 2 . (7.117)

Key features.

  • The product does not depend on σ : squeezing the packet in position broadens it in momentum by the same factor.

  • The Gaussian wave packet attains the minimum ℏ / 2 allowed by the uncertainty principle.

  • This is the width–bandwidth relation of the rectangular pulse, multiplied by ℏ .

7.5The Fourier Transform in Two and Three Dimensions

Video Lecture 21, Part 6: The Fourier Transform in 2D (25:59)

The functions considered so far depend on one variable. An image is a function of two variables, its brightness f ( x , y ) , and a field in space is a function of three. The Fourier transform extends to these cases directly; the new feature is that a wave in more than one dimension has a direction.

Plane waves and the wave vector

In one dimension, the wave e i k x is characterized by a single wave number k . In two dimensions, a plane wave is characterized by its wave numbers along x and along y , which form the wave vector k → = ( k x , k y ) . With r → = ( x , y ) , the exponent is a dot product:

e i ( k x x + k y y ) = e i k → ⋅ r → (7.129)

  • Wavefronts. The phase k → ⋅ r → is constant on lines perpendicular to k → . The wavefronts are therefore parallel lines perpendicular to k → , and the wave propagates along k → .

  • Wavelength. λ = 2 π / | k → | , as in one dimension; a longer wave vector means a shorter wavelength.

  • Three dimensions. k → = ( k x , k y , k z ) and k → ⋅ r → = k x x + k y y + k z z . The wavefronts are planes perpendicular to k → , hence the name plane wave.

DefinitionFourier Transform in Two and Three Dimensions

The one-dimensional transform is applied along each axis, with a factor 1 2 π for each:

g ( k x , k y ) = 1 ( 2 π ) 2 ∬ f ( x , y ) e − i ( k x x + k y y ) d x d y , f ( x , y ) = ∬ g ( k x , k y ) e i ( k x x + k y y ) d k x d k y , (7.130)
g ( k → ) = 1 ( 2 π ) 3 ∫ f ( r → ) e − i k → ⋅ r → d 3 r , f ( r → ) = ∫ g ( k → ) e i k → ⋅ r → d 3 k , (7.131)

where d 3 r = d x d y d z runs over all of space and d 3 k = d k x d k y d k z .

Reading a two-dimensional transform

The transform g ( k x , k y ) can itself be displayed as an image on the k -plane. Each point ( k x , k y ) represents one plane wave, and | g | at that point is its amplitude in f . Points near the origin correspond to long wavelengths, which carry the large-scale structure of an image; points far from the origin correspond to short wavelengths, which carry its fine detail.

The Dirac delta function. The transform of a single plane wave is concentrated at one point of the k -plane. To describe it we need the Dirac delta function δ ( k ) , which is zero for every k ≠ 0 and has unit area:

δ ( k ) = 0     ( k ≠ 0 ) , ∫ − ∞ ∞ δ ( k ) d k = 1 , so ∫ − ∞ ∞ F ( k ) δ ( k − k 0 ) d k = F ( k 0 ) . (7.132)

It is the limit of a peak that becomes ever taller and narrower while keeping unit area. An example is the transform of the rectangular pulse, sin ⁡ ( k a ) / π k , as a → ∞ : its height a / π grows, its width π / a shrinks, and its area stays 1 . The inverse transform of δ ( k − k 0 ) is ∫ δ ( k − k 0 ) e i k x d k = e i k 0 x , so the transform of a single plane wave is a delta function:

1 2 π ∫ − ∞ ∞ e i k 0 x e − i k x d x = δ ( k − k 0 ) . (7.133)

An image of parallel stripes has brightness f ( x , y ) = cos ⁡ ( k → 0 ⋅ r → ) , where k → 0 = ( k 0 x , k 0 y ) is a fixed wave vector. The brightness is greatest where k → 0 ⋅ r → is a multiple of 2 π , and the stripes are perpendicular to k → 0 .

ExampleTransform of a stripe pattern

Find the two-dimensional Fourier transform of the stripe pattern

f ( x , y ) = cos ⁡ ( k → 0 ⋅ r → ) = cos ⁡ ( k 0 x x + k 0 y y ) . (7.134)

We use

g ( k x , k y ) = 1 ( 2 π ) 2 ∬ f ( x , y ) e − i ( k x x + k y y ) d x d y , 1 2 π ∫ − ∞ ∞ e − i ( k − k 0 ) x d x = δ ( k − k 0 ) . (7.135)

The unknown is g ( k x , k y ) : which plane waves the image contains.

Solution.

Step 1. Write the transform.

g ( k x , k y ) = 1 ( 2 π ) 2 ∬ cos ⁡ ( k 0 x x + k 0 y y ) e − i ( k x x + k y y ) d x d y . (7.136)

Step 2. Write the cosine in exponential form. With cos ⁡ θ = 1 2 ( e i θ + e − i θ ) ,

g ( k x , k y ) = 1 2 1 ( 2 π ) 2 ∬ e − i [ ( k x − k 0 x ) x + ( k y − k 0 y ) y ] d x d y + 1 2 1 ( 2 π ) 2 ∬ e − i [ ( k x + k 0 x ) x + ( k y + k 0 y ) y ] d x d y . (7.137)

Step 3. Separate the double integrals. Each exponential is a product of a function of x and a function of y , so each double integral is a product of two single integrals. For the first term,

1 ( 2 π ) 2 ∬ e − i ( k x − k 0 x ) x e − i ( k y − k 0 y ) y d x d y = [ 1 2 π ∫ e − i ( k x − k 0 x ) x d x ] [ 1 2 π ∫ e − i ( k y − k 0 y ) y d y ] . (7.138)

Step 4. Evaluate each single integral. By the delta-function result, the brackets are δ ( k x − k 0 x ) and δ ( k y − k 0 y ) . The second term is the same with k → 0 replaced by − k → 0 .

Result.

g ( k x , k y ) = 1 2 δ ( k x − k 0 x ) δ ( k y − k 0 y ) + 1 2 δ ( k x + k 0 x ) δ ( k y + k 0 y ) . (7.139)

Key features.

  • g is zero everywhere except at the two points k → = + k → 0 and k → = − k → 0 (Figure 7.19): the image contains exactly two plane waves.

  • Rotating the stripes rotates the two points about the origin.

  • Closer stripes (shorter wavelength 2 π / | k → 0 | ) move the two points farther from the origin.

Scanners and electrical interference can superimpose a periodic stripe pattern on an image. Figure 7.20 (left) shows a portrait of Fourier corrupted in this way. Its brightness is the face plus one stripe pattern; the face varies slowly across the image.

ExampleRemoving periodic noise from an image

The brightness of a corrupted portrait is

f ( x , y ) = f face ( x , y ) + c cos ⁡ ( k → 0 ⋅ r → ) . (7.140)

Use the two-dimensional Fourier transform to remove the stripes while leaving the face unchanged. We use the transform pair of the definition and the transform of the stripe pattern from the previous example. The unknown is a modified transform whose inverse is f face .

Solution.

Step 1. Transform the image. The transform is linear, so the transform of f is the sum of the transforms of its two terms. By the previous example,

g ( k → ) = g face ( k → ) + c 2 δ ( k → − k → 0 ) + c 2 δ ( k → + k → 0 ) , (7.141)

where δ ( k → − k → 0 ) = δ ( k x − k 0 x ) δ ( k y − k 0 y ) .

Step 2. Locate the two contributions. The face varies slowly, so g face is concentrated near the origin of the k -plane. The stripes appear as two isolated peaks at ± k → 0 , away from the face (Figure 7.20, middle).

Step 3. Filter. Set g to zero in a small disk around each of the points ± k → 0 . This removes the two delta functions, and changes g face only where it is already negligible:

g filtered ( k → ) ≈ g face ( k → ) . (7.142)

Step 4. Transform back.

f filtered ( x , y ) = ∬ g filtered e i ( k x x + k y y ) d k x d k y ≈ f face ( x , y ) . (7.143)

Result. The stripes are removed and the face is unchanged (Figure 7.20, right).

Key features.

  • The method works because the noise and the image occupy different regions of the k -plane.

  • Image-processing software removes periodic noise in the same way.

Diffraction

Video Lecture 21, Part 7: Light Through an Opening (31:44)

Diffraction is the spreading of a wave after it passes through an aperture. Light passing through a wide aperture continues almost in a straight line; an aperture comparable in size to the wavelength λ spreads it over a wide range of angles.

Let light of wavelength λ pass through an aperture in an opaque screen and fall on a distant screen. By Huygens' principle, each point of the aperture acts as a source of waves. In a direction at angle θ to the forward direction, the wave from a point at height x travels an additional distance x sin ⁡ ( θ ) and therefore acquires the phase k 0 x sin ⁡ ( θ ) , where k 0 = 2 π / λ . Summing these contributions over the aperture gives the amplitude on the distant screen:

amplitude ∝ ∬ A ( x , y ) e − i ( k x x + k y y ) d x d y , k x = k 0 sin ⁡ ( θ x ) , k y = k 0 sin ⁡ ( θ y ) , (7.144)

where the aperture function A ( x , y ) is 1 inside the aperture and 0 outside, and θ x , θ y are the horizontal and vertical angles. The amplitude is therefore the two-dimensional Fourier transform of the aperture; the observed intensity is its squared magnitude.

ExampleDiffraction by a square aperture

Find the diffraction pattern of a square aperture of side w centred at the origin,

A ( x , y ) = { 1 , | x | < w / 2  and  | y | < w / 2 , 0 , otherwise , (7.145)

and the angles at which the intensity is zero. How does the pattern change as w decreases? We use the diffraction formula above. The unknown is the intensity I ∝ | amplitude | 2 as a function of θ x and θ y .

Solution.

Step 1. Restrict the integral to the aperture. A = 1 inside the square and 0 outside, so

amplitude ∝ ∫ − w / 2 w / 2 ∫ − w / 2 w / 2 e − i k x x e − i k y y d x d y . (7.146)

Step 2. Separate the double integral.

amplitude ∝ [ ∫ − w / 2 w / 2 e − i k x x d x ] [ ∫ − w / 2 w / 2 e − i k y y d y ] . (7.147)

Step 3. Evaluate each integral. As for the rectangular pulse,

∫ − w / 2 w / 2 e − i k x x d x = e − i k x w / 2 − e i k x w / 2 − i k x = 2 sin ⁡ ( k x w / 2 ) k x , (7.148)

and the same with y in place of x .

Step 4. Square to obtain the intensity.

I ∝ [ sin ⁡ ( k x w / 2 ) k x ] 2 [ sin ⁡ ( k y w / 2 ) k y ] 2 . (7.149)

Each factor takes its largest value, ( w / 2 ) 2 , at k = 0 (straight ahead).

Step 5. Find the zeros. The intensity vanishes when sin ⁡ ( k x w / 2 ) = 0 with k x ≠ 0 , that is, k x w / 2 = m π with m = ± 1 , ± 2 , … With k x = ( 2 π / λ ) sin ⁡ ( θ x ) , this gives sin ⁡ ( θ x ) = m λ / w , and similarly for θ y .

Result.

I ∝ [ sin ⁡ ( k x w / 2 ) k x ] 2 [ sin ⁡ ( k y w / 2 ) k y ] 2 , zeros at  sin ⁡ ( θ x ) = m λ w ,     sin ⁡ ( θ y ) = m λ w . (7.150)

Key features.

  • Each factor is large only when its own k is near zero, so the light is concentrated along the two axes: a cross-shaped pattern (Figure 7.21).

  • Reducing w moves the zeros to larger angles: a smaller aperture produces a wider pattern, in accordance with the width–bandwidth relation.

A circular aperture of diameter D has circular symmetry, so its diffraction pattern is a central bright disk surrounded by concentric rings (the Airy pattern, Figure 7.21). Its transform involves a Bessel function and is not derived here; the first dark ring occurs at sin ⁡ ( θ ) = 1.22 λ / D . This limits the angular resolution of a telescope of diameter D to about 1.22 λ / D .

RemarkSeparable functions

g ( k ) = 1 ( 2 π ) 3 ∫ 0 ∞ r 2 f ( r ) d r ∫ 0 2 π d ϕ ∫ 0 π e − i k r cos ⁡ ( θ ) sin ⁡ ( θ ) d θ . (7.153)

The ϕ integral gives 2 π . With u = cos ⁡ ( θ ) , the θ integral is ∫ − 1 1 e − i k r u d u = 2 sin ⁡ ( k r ) k r . Combining these factors gives the result.

In the ground state of the hydrogen atom, the electron's wave function is

ψ ( r ) = e − r / a π a 3 , (7.154)

where a = 0.529 Å is the Bohr radius. As in one dimension, the momentum-space wave function is the (three-dimensional) Fourier transform g ( k → ) , and p → = ℏ k → . Since g will not be a Gaussian, we measure its width by the half width at half maximum (HWHM): the value of k at which g falls to half its peak value, that is, half the FWHM.

( 1 + a 2 k 2 ) 2 = 2 ⇒ a 2 k 2 = 2 − 1 ⇒ Δ k = 2 − 1 a ≈ 0.64 a . (7.161)

Step 7. Estimate the speed. With p = m v ≈ ℏ Δ k ,

v ≈ 0.64 ℏ m a = 0.64 ( 1.055 × 10 − 34 ) ( 9.11 × 10 − 31 ) ( 0.529 × 10 − 10 )   m/s = 1.4 × 10 6   m/s . (7.162)

Result.

g ( k ) = a 3 / 2 π 5 / 2 ( 1 + a 2 k 2 ) 2 , Δ k ≈ 0.64 a , v ≈ 1.4 × 10 6   m/s . (7.163)

Key features.

  • The width in k is of order 1 / a : the smaller the atom, the broader its momentum distribution.

  • The root-mean-square momentum computed from | g ( k ) | 2 is exactly ℏ / a (the integral is not evaluated here), which gives v = ℏ / m a = 2.2 × 10 6 m/s ≈ c / 137 . Both estimates give the same order of magnitude.

7.6The Fourier Series as an Eigenvalue Problem

Video Lecture 21, Part 9: Beyond Sines and Cosines (43:35)

Why can sines and cosines represent essentially any function? The answer is the same as for symmetric matrices in Chapter 3: a symmetric matrix has orthogonal eigenvectors that form a basis. Here the matrix is replaced by a differential operator, and the eigenvectors by eigenfunctions.

The differential equation as an eigenvalue problem

Recall from Chapter 3 that a symmetric matrix A has eigenvectors A e → n = λ n e → n . Eigenvectors belonging to different eigenvalues are orthogonal, and together they form a basis: any vector can be expanded as v → = ∑ n c n e → n with c n = v → ⋅ e → n / ( e → n ⋅ e → n ) .

Now consider a string of length L fixed at both ends and the operator ℒ = − d 2 d x 2 ( ℒ denotes the operator and L the length; the minus sign makes the eigenvalues positive). Its eigenvalue problem is a differential equation with a boundary condition at each end:

ℒ u n ( x ) = λ n u n ( x ) , u n ( 0 ) = u n ( L ) = 0 . (7.164)

Its solutions are

u n ( x ) = sin ⁡ n π x L , λ n = ( n π L ) 2 , n = 1 , 2 , 3 , … (7.165)

Applying ℒ to u n returns u n multiplied by a constant, just as A e → n = λ n e → n . Thus u n is an eigenfunction of ℒ with eigenvalue λ n . The correspondence is summarized below.

TheoremOrthogonality of the eigenfunctions

If u and v vanish at both ends, two integrations by parts give ∫ 0 L u ( ℒ v ) d x = ∫ 0 L ( ℒ u ) v d x : the operator is symmetric, like the matrix A . Applied to two eigenfunctions, this gives

λ m ∫ 0 L u n u m d x = ∫ 0 L u n ( ℒ u m ) d x = ∫ 0 L ( ℒ u n ) u m d x = λ n ∫ 0 L u n u m d x , (7.166)

so ( λ n − λ m ) ∫ 0 L u n u m d x = 0 : eigenfunctions with different eigenvalues are orthogonal.

There is one eigenfunction for each n , and together they form a complete set: any reasonable function f on [ 0 , L ] can be expanded as f = ∑ n c n u n with c n = 2 L ∫ 0 L f ( x ) sin ⁡ n π x L d x , which is the Fourier sine series. With the periodic condition u ( x + L ) = u ( x ) in place of fixed ends, the same operator has the eigenfunctions e i k n x , and the expansion is the complex Fourier series of this chapter (for complex functions the inner product is ∫ f g ∗ d x ).

Sturm–Liouville problems

The argument used only one property of ℒ , its symmetry, and many equations of physics share this property. A string whose mass per unit length w ( x ) varies along its length vibrates according to T u ″ = − ω 2 w ( x ) u ; heat conduction in a nonuniform bar, the problem studied by Sturm and Liouville in the 1830s, leads to an equation of the same type.

TheoremSturm–Liouville

Consider the operator

ℒ u = 1 w ( x ) [ − d d x ( p ( x ) d u d x ) + q ( x ) u ] , ℒ u n = λ n u n , a ≤ x ≤ b , (7.167)

with p > 0 , w > 0 , and a boundary condition at each end (for example u = 0 ). Then:

  1. the eigenvalues λ n are real;

  2. eigenfunctions with different eigenvalues are orthogonal with respect to the weight function w : ∫ a b w u n u m d x = 0 for n ≠ m ;

  3. the eigenfunctions form a complete set: any f with ∫ a b w f 2 d x finite can be expanded as

    f ( x ) = ∑ n c n u n ( x ) , c n = ∫ a b w f u n d x ∫ a b w u n 2 d x . (7.168)

For piecewise smooth f the series converges to f wherever f is continuous, and to the average of the one-sided limits at a jump, as in the Dirichlet theorem.

The Fourier series is the special case p = w = 1 , q = 0 . In general the weight w defines a weighted inner product, ∫ a b w f g d x .

Consider a string of unit length, fixed at both ends and held at tension T , whose mass per unit length increases along the string as w ( x ) = 1 + 3 x . In a normal mode every point oscillates as u ( x ) cos ⁡ ( ω t ) , and Newton's second law gives T u ″ = − ω 2 w ( x ) u . The modes cannot be found in closed form; they are computed numerically and normalized so that ∫ 0 1 w u n 2 d x = 1 .

ExampleA string of nonuniform density

The modes of the string satisfy

− 1 w ( x ) u ″ = λ u , u ( 0 ) = u ( 1 ) = 0 , w ( x ) = 1 + 3 x , λ = ω 2 T . (7.169)
  1. (a)

    Identify p , q and the weight function in the Sturm–Liouville form.

  2. (b)

    The first two modes give ∫ 0 1 u 1 u 2 d x = 0.081 (each chosen positive near x = 0 ). Which integral of u 1 u 2 vanishes, and why?

  3. (c)

    Find the coefficients c n in the expansion f ( x ) = ∑ n c n u n ( x ) of an initial shape.

We use the Sturm–Liouville form ℒ u = 1 w [ − ( p u ′ ) ′ + q u ] . The unknowns are p , q , w , the vanishing integral, and c n .

Solution.

(a) Compare with the Sturm–Liouville form. The equation is 1 w [ − u ″ ] = λ u , so

p = 1 , q = 0 , w ( x ) = 1 + 3 x     (the mass per unit length) . (7.170)

(b) Step 1. Write the equations of the two modes.

− u 1 ″ = λ 1 w u 1 , − u 2 ″ = λ 2 w u 2 . (7.171)

(b) Step 2. Multiply and integrate. Multiply the second equation by u 1 and the first by u 2 , and integrate over [ 0 , 1 ] :

∫ 0 1 u 1 ( − u 2 ″ ) d x = λ 2 ∫ 0 1 w u 1 u 2 d x , ∫ 0 1 u 2 ( − u 1 ″ ) d x = λ 1 ∫ 0 1 w u 1 u 2 d x . (7.172)

(b) Step 3. Integrate by parts. Since u 1 and u 2 vanish at both ends,

∫ 0 1 u 1 ( − u 2 ″ ) d x = [ − u 1 u 2 ′ ] 0 1 + ∫ 0 1 u 1 ′ u 2 ′ d x = ∫ 0 1 u 1 ′ u 2 ′ d x , (7.173)

and in the same way ∫ 0 1 u 2 ( − u 1 ″ ) d x = ∫ 0 1 u 1 ′ u 2 ′ d x . The two left sides of Step 2 are equal.

(b) Step 4. Subtract.

( λ 2 − λ 1 ) ∫ 0 1 w u 1 u 2 d x = 0 . (7.174)

The eigenvalues are different, so the weighted integral vanishes.

(c) Project onto one mode. Multiply f = ∑ n c n u n by w u m and integrate. By orthogonality, only the term n = m survives, and by the normalization its integral is 1 :

∫ 0 1 w f u m d x = ∑ n c n ∫ 0 1 w u n u m d x = c m . (7.175)

Result.

p = 1 , q = 0 , w = 1 + 3 x ; ∫ 0 1 w u 1 u 2 d x = 0 ; c n = ∫ 0 1 w f u n d x . (7.176)

Key features.

  • The weight is essential: the unweighted integral, 0.081 , does not vanish.

  • The modes are not sine functions; their oscillations are concentrated toward the heavier end (Figure 7.23).

  • The computed eigenvalues, λ n = 3.89 ,   16.05 ,   36.41 , are close to those of a uniform string with the average density w ¯ = 2.5 , λ n = n 2 π 2 / 2.5 = 3.95 ,   15.8 ,   35.5 .

RemarkOther special functions

The same theorem applies to the special functions of later chapters: Legendre polynomials (Chapter 9), which arise in problems with spherical symmetry ( w = 1 on [ − 1 , 1 ] ); Bessel functions, which describe vibrating drums and waves in pipes ( w = x ); and Hermite functions, the eigenfunctions of the quantum harmonic oscillator. Each arises from its own operator, and each forms a complete set with the same coefficient formula; for example, | x | = 1 2 P 0 ( x ) + 5 8 P 2 ( x ) − 3 16 P 4 ( x ) + ⋯ on [ − 1 , 1 ] . Expansion in eigenfunctions is also the method used in Chapter 10 to solve partial differential equations.

7.7Where Fourier Analysis Is Used

The single idea of this chapter — that a function can be rebuilt from sines and cosines, or from complex exponentials — is one of the most widely used in all of physics and engineering. The reason is that the basis functions e i k x are the natural language of anything that oscillates, and of the linear equations that govern waves, heat and quantum systems.

  • Solving partial differential equations. Fourier's original motive was heat flow. Because each mode e i k x evolves independently under the heat, wave and Schrödinger equations, expanding the initial state in modes turns a partial differential equation into a set of ordinary ones. This is the method of Chapter 10.

  • Signal processing. A signal's Fourier coefficients are its frequency content. Filtering, noise removal and compression are all operations on that spectrum, as the low-pass filter of this chapter showed.

  • Spectroscopy and optics. The rectangular-pulse and Lorentzian transforms computed above are exactly the line shapes measured in spectroscopy: the width of a spectral line and the lifetime of the state that produced it are a Fourier transform pair.

  • Quantum mechanics. Position and momentum wavefunctions are Fourier transforms of one another. The width–bandwidth tradeoff seen in the pulse example — narrow in x means wide in k — is, with p = ℏ k , the Heisenberg uncertainty principle.

  • Normal modes. The harmonics of a Fourier series are the standing waves of a vibrating string or air column; their frequencies ν n = n / L are why instruments have a well-defined pitch.

Remark

The width–bandwidth tradeoff deserves a second mention because it recurs under so many names. A pulse of duration Δ t has a spectrum of width Δ ω ∼ 1 / Δ t . In signal processing this limits how sharply a filter can act; in spectroscopy it is the natural linewidth; in quantum mechanics it is Δ x Δ p ≳ ℏ . They are all one statement about Fourier pairs: you cannot make a function narrow in both domains at once.
